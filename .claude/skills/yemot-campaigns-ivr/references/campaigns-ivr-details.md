## 3. ניהול רשימות ע"י מנהל — `yemot_dialer_campaign_list` (post/79)

הוספה / הסרה / חסימה של **מספרים אחרים** (לא של המחייג) ברשימות תפוצה, מהטלפון.

| הגדרה | ערך | משמעות |
|---|---|---|
| `type=yemot_dialer_campaign_list` | — | סוג השלוחה |
| `yemot_dialer_campaign_list_template` | `3` / `1,5,2` / `all` | אילו רשימות מנהלים (בלי — ברירת המחדל) |
| `yemot_dialer_campaign_list_type` | ראו למטה | מצב העבודה |
| `yemot_dialer_campaign_list_no_password=yes` | | ביטול דרישת הסיסמה (כברירת מחדל השלוחה **דורשת סיסמה**) |

ערכי `yemot_dialer_campaign_list_type`:
- `add_remove_block` — כניסה ישירה לתפריט הוספה/הסרה/חסימה
- `add` — הוספת מספרים בלבד
- `add_numbers` — הזנת מספרים בזה-אחר-זה (מצב "הקלדה מרוכזת")
- `reset` — איפוס הרשימה
- `info` — שמיעת מידע על הרשימה

**יומן ביקורת:** כל שינוי נרשם ב-`Log/LogYemotDialerCampaignList.ymgr`.

## 4. הזמנת חבר להצטרף — `invitation_join_campaign` (post/69219)

המערכת מחייגת למספר שהמתקשר מזין ומזמינה אותו להצטרף לרשימה.

| הגדרה | ערך | משמעות |
|---|---|---|
| `type=invitation_join_campaign` | — | סוג השלוחה |
| `invitation_join_campaign_template=X` | | לאיזו רשימת תפוצה מזמינים |
| `invitation_join_campaign_say_did_number=077…` | | איזה מספר-מערכת מוקרא למוזמן |
| קובץ הקלטה `invitationMessage` | < 6 שניות | שם הקו שמושמע למוזמן — **חובה** |

**אצל המוזמן:** 1 = אישור הצטרפות · 2 = סירוב · 3 = חסימת הזמנות עתידיות מהמערכת.
המודול לא מזמין מספר שכבר ברשימה / חסום / חסם את עצמו (M4357: "לא ניתן להזמין
את המספר, ייתכן שהוא כבר ברשימה"). הודעות M4351–M4357. יש הגדרות `..._goto`
לניתוב לפי תוצאה (הצלחה / מספר שגוי / הקלטה גדולה מדי) — ראו הפוסט לפירוט המלא.

### `add_admin_to_list=yes` — ⚠ לא נמצא בתיעוד הפורום

## 8. קמפיין TTS — הקראת טקסט (post/130)

ההגדרה נעשית **בממשק האתר**, לא ב-ext.ini: עורכים את הקמפיין → לשונית ההגדרות →
בתחתית מזינים את הטקסט בשדה עריכת "קמפיין SMS" → שומרים → משגרים כקמפיין קולי
רגיל. **חובה שלא יהיה קובץ שמע בהודעות הקמפיין** (אחרת השמע גובר).
הקול: `voice=Elik_2100` (ברירת מחדל); ניסיון לשנות קול דרך ivr.ini דווח ככושל.
(לאפליקציה שלנו יש TTS משלה — `utils/tts.py` — שעוקף את המגבלה הזו.)

## 11. רשימות צינתוק (tzintuk lists) — `type=tzintuk` (topic/91)

צינתוקים קבוצתיים **ללא עלות יחידות**, על רשימות בצד השלוחה (כמו admins/members
בקו שלנו) — נפרדות לגמרי מרשימות התפוצה (templates).

| הגדרה | משמעות |
|---|---|
| `type=tzintuk` | סוג השלוחה |
| `list_tzintuk=123` | שם הרשימה — **לא ניתן לשינוי אחרי היצירה** |
| `tzintuk_type=removing_to_list` | שלוחת הסרה-בלבד (בלי תפריט) |
| `tzintuk_block_instead_of_remove=yes` | "הסרה" חוסמת במקום למחוק (שלא יצטרפו שוב אוטומטית) |
| `tzintuk_admin=yes` | שלוחת **ניהול**: הפעלת צינתוק לרשימה, מחיקת מספרים, איפוס, ספירת חברים, הזמנות |
| `tzintuk_timeout=9` | משך הצלצול בשניות (עד 10) |
| `tzintuk_your_id=0773137770` | המספר שמוצג לנמעני הצינתוק (בקו שלנו: בשורש ivr.ini) |

שלוחת ההרשמה (בלי `tzintuk_admin`): רק מתקשרים **מזוהים** ממספר **ישראלי**;
תפריט: הוספה / הסרה / הוספה לזמן מוגבל / השתקה זמנית. שמות למספרים: קובץ
`PhonesName.ini` בשלוחה הראשית. בממשק האתר: צפייה ברשימה, דוח פעולות, הפעלת
צינתוק, איפוס.

## 14. `campaign_message_to_play` — הרחבות (post/62038 + post/63431)

הפורמט המלא — ארבעה ערכים מופרדים במקפים: `מספר-קהל-כמות-איפוס`
1. **מספר הקמפיין** (בלי — קמפיין 0). ⚠ ניסיון-שטח בקו שלנו: המספר = **מיקום
   התבנית ברשימת התבניות** (17, 19), לא ה-templateId — ראו yemot-line-knowledge.
2. **קהל היעד**: `ACTIVE` / `BLOCKED` / `NONE` / `ERROR` (בלי — כל המספרים).
3. **מגבלת השמעות** (בלי — ללא הגבלה).
4. **מרווח איפוס**: `thiscall` / שניות-דקות-שעות-ימים-חודשים (`s`/`m`/`h`/`d`/`M`,
   למשל `6d`) / תאריך / `none`.

קובץ-המעקב של ההשמעות (בלעדיו המערכת זוכרת "כבר הושמע").
