# כללי הפרומפט של Claude (Anthropic)

מבוסס על ההמלצות הרשמיות של Anthropic ועל 4 הטכניקות מהסרטון
(https://youtu.be/FBVNS1l5Vb8). המטרה: לנסח את בקשת יהודה כך ש-Claude יבין אותה
לעומק, יתכנן בעצמו, ויחזיר תוצאה מוגמרת — לא טיוטה.

## מה מייחד את Claude
- **חכם בתכנון עצמאי:** אם מגדירים לו *תוצאה* טובה, הוא יודע לפרק את הצעדים לבד.
  לכן **לא צריך למקרו-נהל** אותו צעד-אחר-צעד — זה אפילו מזיק.
- **עוקב אחרי הנחיות ארוכות ומנוסחות היטב** בלי להתבלבל. אפשר לתת הקשר עשיר.
- **מסגור חיובי עדיף:** "עשה X" עדיף על "אל תעשה Y".
- **מבנה עוזר:** כותרות, רשימות, ותיוג ברור של חלקים (בקשה / הקשר / אילוצים /
  פורמט). בהקשר API אפשר גם תגיות `<...>` להפריד חלקים.

## 4 העקרונות ליישם בתרגום

1. **הגדר איך נראית "תוצאה גמורה" (Outcome, לא צעדים):**
   כתוב מה צריך להיות נכון כשהמשימה הושלמה, *למה* היא חשובה, ומה האילוצים —
   ותן ל-Claude לבחור את הדרך. (במקום "קודם תפתח את X, אחר כך תעשה Y".)

2. **התאם רמת מאמץ למשימה:**
   אם המשימה פשוטה — אמור לו לענות מהר/קצר ולהסתמך על הידע שלו בלי לרוץ לכלים.
   אם היא מורכבת/רגישה — בקש חשיבה מעמיקה. (רמת-מאמץ מפורשת חוסכת זמן וטוקנים.)

3. **בקש אימות עצמי לפני שמסיים:**
   הוסף דרישה מפורשת: "לפני שאתה מגיש — בדוק את התוצאה בעצמך (הרץ/צלם/ודא
   עובדות) והצג הוכחה." כך מקבלים תוצאה בדוקה, לא ראשונית.

4. **פירוק והאצלה לסוכני-משנה (למשימות גדולות בלבד):**
   אם המשימה רחבה — הצע לפרק לתת-משימות עצמאיות שירוצו במקביל, כשהמודל המרכזי
   מנהל ומחבר. (לא צריך לכפות — רק לאפשר/להציע.)

## שלד מומלץ לפרומפט ל-Claude
```
[הבקשה בקצרה — מה התוצאה הרצויה]

הקשר: [למה זה נחוץ / רקע שיעזור להחליט נכון]

איך נראה "גמור": [הקריטריונים שחייבים להתקיים בסוף]

אילוצים: [שפה, טון, מה אסור, פורמט הפלט]

רמת מאמץ: [מהיר וקצר / רגיל / מעמיק — לפי גודל המשימה]

לפני שתסיים: ודא בעצמך ש[הבדיקה הרלוונטית] והצג הוכחה.
```

## דגשים ליהודה (עברית / הפרויקט)
- להשאיר עברית ו-RTL כשרלוונטי.
- ל-Claude אפשר לתת הרבה הקשר — הוא לא "נחנק" מזה כמו מודלים קטנים.
- אל תמלא את השלד בכוח: סעיף שלא רלוונטי לבקשה — השמט.
