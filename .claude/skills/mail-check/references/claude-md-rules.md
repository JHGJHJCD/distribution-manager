# מיילים וזרימת המתנדבים — הנוסח המלא מ-CLAUDE.md

> הנוסח המלא של הסעיפים כפי שהיו ב-`CLAUDE.md` עד הקיצור של 4/11/2026 (מילה במילה). ב-CLAUDE.md נשארו רק ההכרעות והאיסורים בתמצית; **כאן = הפירוט המחייב** (שמות פונקציות, מפתחות, מקרי קצה). כששינוי נוגע בנושא — לעדכן כאן.

## מיילים למקבלים (`tabs/mails.py` + `utils/mailer.py` + `utils/google_auth.py`)
**לפני כל עבודה כאן — סקיל `mail-check`** (אינווריאנטים M1–M53, בודק `python .claude/skills/mail-check/scripts/check_mail.py`). פירוט v3.39–v3.55 בקובץ ההיסטוריה.
- מייל לקבוצה/בודדים/כתובות חיצוניות מחשבון Gmail של הקופה, עם placeholders (`{שם}`/`{פרשה}`…); עורך מעוצב (`utils/richtext.py`), כל קריאת גוף דרך `_body_markup()`.
- **חיבור Google** (OAuth, `gmail.send`): ה-token **מסונכרן** (חיבור אחד לשני המחשבים, הכרעה 10/9); **זיהוי-הלקוח המובנה ב-EXE גובר** (הכרעה 14/9 — לא לשנות); הפרויקט ב-Google במצב In production. בלי Google — SMTP עם סיסמת-אפליקציה.
- **שליחה:** תקלה כללית עוצרת את האצווה; התקדמות נשמרת אחרי כל נמען; "שלח שוב לנכשלים" מתאים לפי **guid**; קובץ ≤18MB; מכסת Gmail ≈500 נמענים/יום. בבדיקות: האישור = `QMessageBox.question`, עמודת הפעולות בהיסטוריה = `_HIST_ACT` (6). שאר הכללים — בסקיל.

## זרימת המתנדבים (`utils/email_utils.py` + `utils/excel_utils.py`)
- **שליחה:** `export_volunteer_checklist_to_excel` — אקסל מינימלי, עמודה מוסתרת `id` להתאמה, גיליון `meta` מוסתר, עמודת "הגיע?" עם DataValidation "כן,לא" וברירת מחדל "כן" (המתנדב רק מבטל מי שלא הגיע). **הרזרבה בקובץ = שורות רגילות בלי סימון ועם "כן" (הכרעת יהודה 2/11/2026: להשאיר כך, לא להציע שוב).** `send_email` — multipart + לוגו inline (cid), STARTTLS.
- **ייבוא:** `import_volunteer_checklist` מתאים לפי id המוסתר (fallback לשם), `received = not (ריק/"לא")` — ייבוא ישיר להיסטוריה.
- SMTP דורש **App Password של Gmail** (myaccount.google.com/apppasswords, מצריך 2FA) שמזין המשתמש בהגדרות.
- כל ייצואי האקסל → תיקיית **הורדות** (`_downloads_dir`). לניקוי תא בטסט: `ws.cell(r,c).value = None`.
- (מ-v2.74 כל ייצוא דרך `excel_utils.export_dir(kind)` — תיקייה פר-סוג, פר-מחשב, ברירת מחדל הורדות; מייל למתנדב נרשם גם בהיסטוריית המיילים.)
