## צינתוקים — ימות המשיח (`tabs/tzintukim.py` + `utils/yemot.py`)
**לפני כל עבודה כאן — סקיל `tzintuk-check`** (גדרות בטיחות, אינווריאנטים I1–I53, בודק `python .claude/skills/tzintuk-check/scripts/check_tzintuk.py` — להריץ לפני ואחרי). פירוט v2.82–v3.54 בקובץ ההיסטוריה; התקריות בקו ב-`docs/יומן_פיתוח.md`.
- **מה זה:** הודעה קולית / צינתוק לזכאי החלוקה דרך API של `call2all.co.il/ym/api`. הקו **משותף** (04=קופה, 03=גבאי שבת/555 — זיכרון `reference-shared-yemot-line`). יוצא מ-**048691834** (`DEFAULT_CALLER_ID`; 079 חסום בכשרים). settings מסונכרנות `yemot_*`.
- **רשימה:** רשימת השבוע (`week_rows()` בלי רזרבות) / חלוקה קודמת / רשימה עצמאית; חריגים לא נשלחים. **שליחה:** קלאסי (`RunTzintuk`, **אי אפשר לענות** — אסור `sayInfoOnAnswer`) או "עם הודעה" (`RunCampaign`), תזמון בשרת, שיגור חכם. פקודת חיוג נשלחת **פעם אחת** (בלי retry); הרשומה נכתבת **לפני** הדחיפה לשרת; רשת ברקע. הקלטות: TTS/מיקרופון/קובץ, העלאה עם `convertAudio=1`.
- **אישור הגעה:** סקר **/77** + שרת המענה (Cloudflare, **/76**, מתג `cb_server_enabled`) — `merge_survey_answers`: **fetch ריק/חלקי לעולם לא מוחק תשובה קיימת**. ⚠ שרת המענה **כבוי והניתוב בשורש חסר** (מאז תקרית 15/9; החזרה רק בתיאום עם רון) — סקיל `tzintuk-callback-server`.
### הכרעות ואילוצים קבועים — צינתוקים
- **הכרעות המשתמש:** שליחה **ידנית בלבד** — **אסור** פרסום אוטומטי בשלוחה 1 בשום זרימת שליחה/תזמון (פרסום = כפתור ידני עם דיאלוג אזהרה). **אין חסימת שעות מקומית** (`send_block_reason`→`""`; החסימה היחידה = שבת/חג בשרת, שגיאה 104). **כל המספרים של כל מקבל מצולצלים** (בלי בחירת-מספר; כפילויות בין-שורות מנוקות). **צינתוק קלאסי = ברירת המחדל** (עלות). רק המחשב ששלח צינתוק קלאסי עוקב אחריו. נשארים על אותו קו, בלי DID ייעודי (9/9).
- **אל-תעשה:** התוכנה **לא כותבת לשורש הקו** — שינוי בשורש רק ידני, עם גיבוי+diff, כשהתוכנה סגורה בשני המחשבים. **לא לנסות `f-msg` כשאין הקלטה בשלוחה** (קובץ חסר = "אין מענה"). המנגנון הישן של **שלוחה 78 נעול** (`yemot.CALLBACK_ENABLED=False`) — לא להחזיר. `UpdateTemplate` דוחה `yemotContext=REPEAT` — אין להשתמש בו. לימות **אין API של יומן שיחות עבר** (רק `GetIncomingCalls` חי).
- **כלל-זהב מהתקרית (10/9):** ברירת המחדל של הקו חייבת להישאר על קמפיין "קופה" (OPEN); WHITELIST = כל הקו חסום לכולם.
- **כל פעולה חיה בקו (MCP `pitron-ivr`/API)** — קריאה חופשית, כתיבה רק באישור מפורש של יהודה ובתיאום עם רון.
