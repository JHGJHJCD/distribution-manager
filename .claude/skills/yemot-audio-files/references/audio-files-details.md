# פירוט גולמי — קבצים ושמע בימות המשיח (נאסף 01/09/2026)

כל סעיף מציין את מקורו (post/topic ב-f2.freeivr.co.il). ⚠ = לא אומת במלואו /
תקציר-מכונה שעלול להיות לא מדויק במילה — לאמת מול הפוסט לפני הסתמכות קריטית.

## 1. מודול ההקלטות — `type=record` (post/56973)

### בסיס
```ini
type=record
record_password=XXX        ; סיסמה ייעודית לשלוחת ההקלטות בלבד
```

### הקלטת כותרת
```ini
record_title=tfr    ; תפריט בחירה אם להקליט כותרת
record_title=yes    ; הקלטת כותרת חובה
```

### תפריט האישור בסוף ההקלטה (ברירת מחדל, אחרי הקשת #)
"לשמיעת ההקלטה הקישו 1, לאישור ההקלטה הקישו 2, להקלטה מחודשת 3, לביטול וחזרה הקישו 4":

| מקש | פעולה |
|---|---|
| 1 | שמיעת ההקלטה |
| 2 | אישור ושמירה |
| 3 | הקלטה מחדש |
| 4 | ביטול וחזרה |
| 5 | הקלטת המשך (המשך מאותו קובץ) |

קיצורי-דרך על התפריט:
```ini
record_ok=#               ; הקשת # מאשרת מיד (בלי תפריט)
record_stop_any_key=yes   ; כל מקש מסיים את ההקלטה
say_record_number=no      ; לא להקריא את מספר הקובץ שנשמר
say_record_menu=no        ; לדלג על "להקלטה נוספת..."
hangup_insert_file=yes    ; ניתוק באמצע = ההקלטה נשמרת בכל זאת כקובץ השמעה רגיל
```

### משך וזיהוי שקט
```ini
option_record=3-5-10   ; שקט-מינימום-מקסימום (שניות): ניתוק אחרי 3 שנ' שקט,
                       ; הקלטה קצרה מ-5 שנ' נפסלת, מקסימום 10 שנ'
```

### שם הקובץ
- ברירת מחדל: מספור אוטומטי — "השם של הקובץ החדש ממוספר אוטומטית כמספר הגבוה
  ביותר" בשלוחת היעד (החדש תמיד עליון ב-playfile ברירת-מחדל).
- `set_record_name=yes` — המקליט מקיש בעצמו את מספר הקובץ.

### לאן נשמרת ההקלטה — `folder_move`
```ini
folder_move=this_folder   ; לשלוחה הנוכחית (ברירת מחדל)
folder_move=/7            ; לשלוחה אחרת (נתיב מלא מהשורש)
folder_move=tfr           ; המקליט בוחר יעד בזמן ההקלטה
folder_move=template      ; לרשימת תפוצה (תבנית קמפיין)
```
⚠ מלכודת (מתועדת ב-yemot-line-knowledge): הנתיב חייב להתאים **במדויק** לשם
השלוחה (`07/3` ≠ `7/3`) — נתיב שגוי = ההקלטה נעלמת בלי שגיאה.

### שכפול/קישור
```ini
copy_record_link=yes   ; יוצר לינק של הקובץ לתיקייה נוספת
hard_link=yes          ; לינק קשיח — לא נפגע ממחיקת המקור
```

### אחרי ההקלטה
```ini
record_end_goto=/2        ; יעד אם ההקלטה אושרה
record_cancel_goto=/3     ; יעד אם בוטלה
record_end_run_tzintuk=yes  ; שיגור צינתוק אוטומטי בסיום
list_tzintuk=123            ; מספר רשימת התפוצה לצינתוק
email_send=yes              ; שליחת ההקלטה למייל
record_send_sms=yes         ; התראת SMS בסיום
record_send_sms_to=05XXXXXXXX
record_change_pitch=0.5     ; עיוות קול: 0.5 (נמוך) עד 1.5 (גבוה)
```

### יומן
כל שלוחת record מנהלת `record_log.ymgr` (מי הקליט, מתי, איזה קובץ) — שימש
בתחקיר קיפאון שלוחה 1 (ראו yemot-line-knowledge).

## 2. שלוחת השמעת קבצים — `type=playfile` (post/68755)

ההגדרה החובה היחידה: `type=playfile`. ראו גם הסיכום הקהילתי הרחב:
`yemot-line-knowledge/references/community/03-menu-playfile-record-confbridge.md`.

### סדר השמעה
```ini
start=max      ; ברירת מחדל — מהקובץ הגבוה לנמוך (החדש ביותר קודם)
start=min      ; מהנמוך לגבוה
start=select   ; תפריט בחירת קובץ
random=1       ; אקראי — "קובץ שהושמע לא יושמע פעם נוספת" באותה שיחה
last_play_auto=yes  ; המשך אוטומטי מנקודת העצירה האחרונה של המאזין
```

### מספור קבצים
קבצים נשמרים במספור של **3 ספרות מינימום** (000, 001, 002…). שינוי כמות
הספרות: `file_amount_digits`. (תואם post/62514 — המערכת הישנה מיספרה
אוטומטית; החדשה מאפשרת גם שמות מקוריים.)

### מקשים בזמן השמעה (ברירות מחדל) ⚠ תקציר — לאמת שמות מדויקים בפוסט
| מקש | פעולה | שם פנימי |
|---|---|---|
| 1 | אחורה 10 שניות | `seconds_minus` |
| 3 | קדימה 10 שניות | `seconds_plus` |
| 2 | קובץ גבוה יותר | `plus` |
| 8 | קובץ נמוך יותר | `minus` |
| # | חזרה שלב למעלה | `return` |

הזמנים ניתנים להתאמה. מערך מקשים מלא (6 קידומות `control_play*`) — מפורט
בקובץ הקהילתי 03 הנ"ל.

### סוף ההשמעה
```ini
playfile_end_goto=/5/8          ; יעד בסיום כל הקבצים (ברירת מחדל: חזרה שלב אחורה)
after_play=return               ; ⚠ חזרה אחורה בסיום (תקציר — לאמת)
after_play_tfr=tfr_more_options ; ⚠ תפריט אפשרויות אחרי כל השמעה (תקציר — לאמת)
```

### ארכיון Old (מתועד בהרחבה ב-yemot-line-knowledge, f2 topic/12741)
```ini
playfile_move_file_to_old=yes  ; קובץ שנשמע עובר גלובלית ל-Old — מסוכן לקו ציבורי!
playfile_end_play_old=yes|tfr  ; שמיעת הישנות אוטומטית / בתפריט בסוף
```

### מעקב האזנה
```ini
listening_mark=yes          ; סימון קבצים שנשמעו
check_if_listening_ok=yes   ; בדיקה אם המאזין כבר שמע
log_playback_play_stop=yes  ; יומן נתוני האזנה (התחלה/עצירה)
```

## 3. `play_and_return` — שני מובנים שונים!

1. **סוג שלוחה** `type=play_and_return` — "השמעת הודעה אחת בלבד" וחזרה לשלוחה
   הקודמת (רשימת סוגי השלוחות, topic/78).
2. **הגדרה** `play_and_return=play_all` — בשלוחה רגילה: הודעת הפתיח "תושמע עד
   הסוף ללא אפשרות דילוג" (post/2899).

## 4. קבצי TTS (post/2902, topic/8325, topic/5646, post/89921)

### מהות ותחביר
- קובץ טקסט רגיל בקידוד **UTF-8** עם סיומת `.tts`; המערכת מקריאה את תוכנו
  בקול סינתטי. שמות לדוגמה: `000.tts`, `M0000.tts` (כלומר גם הודעות מערכת
  אפשר כ-TTS!).
- עד **~1,300 תווים** כולל רווחים לקובץ.
- **אסור קובץ WAV מקביל באותו שם** — המערכת תעדיף את ה-WAV ותתעלם מה-tts.
- כמה קבצי tts בשלוחה — מושמעים ברצף לפי הסדר.
- יצירה: מהמחשב (Notepad → שמירה UTF-8 בסיומת .tts) או מאשף ההגדרות באתר
  ("השמעת קבצים" → קובץ הקראה).

### קול ומהירות (topic/5646) — ב-ext.ini של השלוחה או ivr.ini לכלל המערכת
```ini
voice=Elik_2100   ; ברירת המחדל
voice=Jacob
voice=Sivan
voice=Osnat
rate=0            ; מהירות: ‎-10 (איטי) עד 10 (מהיר), ברירת מחדל 0
```
ההגדרה חלה על **כל** קבצי ה-tts שבשלוחה.

### מודול יצירת TTS מהטלפון — `type=create_tts` (post/89921)
המתקשר מקליד/מקליט והמערכת יוצרת קובץ tts:
```ini
type=create_tts
create_tts_type=keyboard        ; הקלדה במקשים | record = הקלטה קולית שמומרת לטקסט
create_tts_in_folder=1/1        ; יעד הקובץ (ברירת מחדל: השלוחה הנוכחית) | tfr = בחירה
create_tts_record_option=6-5-10 ; שקט-מינ'-מקס' (ברירת מחדל 2-2-20)
create_tts_select_file_number=yes  ; המשתמש בוחר את מספר הקובץ
create_tts_add_val_name=yes     ; הוספת שם המתקשר (מהזיהוי) לתוכן
create_tts_record_ok=#          ; אישור מיידי בלי תפריט
create_tts_end_goto=1/1         ; יעד בהצלחה (או hangup)
create_tts_error_goto=/1/1      ; יעד בשגיאה
```
הודעות המערכת המלוות: M3969–M3975.
⚠ `create_tts` לא הופיע ברשימת סוגי השלוחות topic/78 — כנראה רשימה ישנה; המודול
מתועד בפוסט ייעודי.

## 5. פורמט הקבצים (post/62514)

- הפורמט הפנימי: **WAV מסוג Windows PCM, ‏8000Hz, ‏16-bit, מונו**.
- העלאה דרך **האתר** — המרה אוטומטית לפורמט הנדרש.
- העלאה דרך **FTP** — חובה להמיר ידנית מראש לפורמט המדויק.
- העלאה דרך **ה-API** — `UploadFile` עם `convertAudio=1` ממיר בצד השרת
  (כך האפליקציה מעלה MP3 של Edge-TTS; אומת בשטח, ראו CLAUDE.md).
- להקפיד על מקור באיכות גבוהה לפני ההמרה (8kHz טלפוני "מוריד" הרבה).

### קובץ שקט תקין (post/60816)
כשרוצים "להשתיק" הודעת מערכת — **לא** להעלות קובץ ריק (0 בייטים): חלקים
מהמערכת סובלים זאת, אבל למשל חדרי ועידה **נכשלים**. יש להשתמש בקובץ
`quiet.wav` תקין (קובץ שקט אמיתי, מצורף לפוסט) בכל מקום שנדרש "שקט".

## 6. הודעות מערכת — קבצי M (post/3, post/4, post/2899)

### הרשימה (post/3)
- כ-150 הודעות, מ-M0000 עד M1148 (הטבלה עודכנה 24/02/2025), בשפות: עברית,
  עברית-קול-וואטסאפ, אידיש, אנגלית.
- דוגמאות: **M0000** = "ברוכים הבאים — הודעה ראשונה בשלוחה" (הודעת הפתיח);
  **M1000** = "זהו תפריט בחירה. אנא הקישו את מספר השלוחה המבוקש";
  M1001 = "מקש לא חוקי"; M1002 = "לא בוצעה בחירה"; M1100–M1102 = סיסמה/שגיאה/הרשאות.

### החלפה והרחבה
- מעלים קובץ בשם ההודעה (למשל `M1000.wav`) **לשלוחה** — והוא מחליף את הודעת
  המערכת באותה שלוחה. אפשר גם `M0000.tts` (טקסט מוקרא, post/2902).
- **קבצי המשך** (post/2899): "בחלק מהודעות המערכת ניתן להוסיף הודעת המשך…
  על ידי הוספת `-1` לשם ההודעה": `M0000`, `M0000-1`, `M0000-2`, `M0000-3`.
- הגדרות נלוות (post/2899): `play_and_return=play_all` = שמיעת חובה של הפתיח;
  `say_first_one_time=yes` = M0000 יושמע רק פעם אחת לכל שיחה.
- ⚠ "שלוש רמות חיפוש" (שלוחה → שורש/main → ברירת מחדל של המערכת): לא נמצא
  ציטוט מפורש בפוסטים שנבדקו. מה שכן מתועד: קובץ M בשלוחה מחליף בשלוחה
  (post/3-related), ו-`record_system_folder=main` שולח הקלטת-מערכת ל"תיקייה
  הראשית" (post/4) — כלומר קיימת רמת-שורש. להשלים ציטוט כשיימצא.

### הקלטת הודעות מערכת מהטלפון — `type=record_system_messages` (post/4)
```ini
type=record_system_messages
record_system_folder=/8/8    ; לאיזו שלוחה שייכת ההודעה | main = התיקייה הראשית
record_system_messages=M1000 ; לקבע מראש איזו הודעה מקליטים (בלי הקשת 4 ספרות)
record_system_messages_end_goto=/5  ; יעד בסיום
record_system_messages_plus=yes     ; הודעות "מורחבות" — מקישים כוכבית במקום מקף
```
תומך גם ב"הודעות זמניות" עם תוקף (דקות/שעות/ימים/חודשים).

## 7. הודעות מתחלפות לפי זמן

### `type=daily_message` — הודעה יומית מתחלפת (post/33)
סדר החיפוש (הראשון שנמצא מושמע):
1. `YYYY-MM-DD.wav` (למשל `2017-08-18.wav`); עם `date=hebrew` — לפי תאריך עברי.
2. רשומה לתאריך בקובץ `daily_message.ini`.
3. קובץ לפי יום בשבוע — `N.wav` (⚠ המספור כנראה א'=1... ש'=7 — לא צוטט מפורשות).
4. רשומת יום-בשבוע ב-ini.
5. `default.wav`.
6. הודעת ברירת-מחדל מוקראת (TTS).

מקשים: `*` = סיום ההשמעה, `#` = יציאה מיידית; `skip_by_any_key=yes` = כל מקש
מדלג (חוץ מ-#); 3 = קפיצה 10 שנ' קדימה, 6 = אחורה. בסיום —
`daily_message_end_goto=` או חזרה לתפריט הקודם.

### `type=toplay_time` — הודעה בזמנים/מועדים (post/32) ⚠ שמות שדות לאמת בפוסט
- לוחות נתמכים: לועזי (`g=`), עברי (`h=`), ספירת העומר, חנוכה.
- 7 רכיבי תזמון: שעה-ביום, ימים-בשבוע, ימים-בחודש, חודשים, שנים + 3 הגדרות
  תדירות אופציונליות: כמה זמן לא להשמיע שוב (שניות עד תאריך; `thiscall` = פעם
  בשיחה), מקסימום השמעות לתקופה, מתי מתאפס המונה.
- `toplay_time_log_save=yes` — יומן השמעות בתיקייה.
- בפוסט 7 דוגמאות מעשיות (כגון "כל יום חול 9:00–17:00 ביוני בלבד").


## 9. דוחות ymgr (post/78987, post/1984, topic/11197)

### מהות
`.ymgr` = קובצי דוח/יומן פנימיים של המערכת (רישום פעולות: הקלטות, כניסות,
הרשמות…). מבנה טבלאי: כל שורה = רשומה; **`#` מפריד שדות, `%` מפריד בין
כותרת לערך** (`Folder#1%Phone#05...%EnterDate#...`). שדות סטנדרטיים: מערכת,
שלוחה, טלפון, תאריך, שעה + שדות ייחודיים למודול.

### צפייה והמרה
1. **בממשק הניהול** — כפתור ייצוא: HTML (לדפדפן) או CSV (לאקסל).
   אקסל מוגבל למיליון שורות; קובץ CSV לפתוח דרך אשף ייבוא-טקסט עם UTF-8
   (פתיחה ישירה = ANSI = ג'יבריש בעברית).
2. **ידנית** (post/1984): פותחים ב-Notepad → החלף-הכל `#`→פסיק, `%`→פסיק,
   `/`→נקודה (שלא יתפרש כתאריך) → שמירה כ-CSV → אקסל.
3. **API — `RenderYMGRFile`** (topic/11197):
   ```
   https://call2all.co.il/ym/api/RenderYMGRFile?wath=ivr2:/1/file.ymgr&convertType=csv&LoadLang=1&token=מספר:סיסמה
   ```
   - ⚠ שם הפרמטר הוא **`wath`** (שגיאת כתיב היסטורית של ימות — לא `what`!
     בשונה מ-DownloadFile שמשתמש ב-`what`). כך מופיע בשני מקורות.
   - `convertType`: `csv` / `html` / `json`.
   - `LoadLang=1` = שמות עמודות מותאמים + הסתרת שדות מוסתרים; `notLoadLang` /
     `LoadLang=0` = גולמי.
   - שילוב באקסל: נתונים ← מהאינטרנט ← הדבקת ה-URL ← טבלה מתרעננת.

### התאמת תצוגה

## 10. העלאה/הורדה דרך ה-API החיצוני (מתועד בהרחבה בסקיל הענן yemot-hamashiach)

- `UploadFile` — העלאת קובץ שמע; עם `convertAudio=1` השרת ממיר לפורמט טלפוני
  (ככה `utils/yemot.py upload_message_wav` עובד; אומת בשטח).
- `DownloadFile` — הורדה (`what=ivr2:/1/000.wav`; לתבניות `tpl:<id>`).
- `UploadTextFile` / `GetTextFile` — קבצי טקסט (ini/tts) בקידוד נכון.
- `GetIVR2Dir` — תוכן תיקייה (כך מאתרים את המספר הפנוי הבא בשלוחה —
  `yemot.publish_to_extension`).
- `RenderYMGRFile` — ראו סעיף 9.
