## 1. מודול routing — הטבלה המלאה (post/734)

בסיס:

```ini
type=routing
```

### דרכי בחירת היעד

| תצורה | מפתחות | הערות |
|---|---|---|
| מספר בודד | `routing_to_phone=0581234567` | הצורה הפשוטה |
| לפי המספר שחויג | `routing_to_phone=by_incoming_did` | דורש קובץ `RoutingIncomingDID.ini` בשלוחה; שורות `DID=מספר-יעד` (למשל: כל שיחה שנכנסה ל-0772222770 מנותבת ל-0501234567, ול-0773137770 → מספר אחר). שימושי למערכת "מספרים וירטואליים" (topic/218) |
| תפריט בחירה במקש | `routing1=0501111111`, `routing2=0523333333`, `digits=2` | המתקשר מקיש ספרה ומנותב ל-routingX המתאים |
| כמה מספרים ביחד | `routing_multiple=yes` + `routing_multiple_numbers=1,3` | מחייג בו-זמנית ל-routing1 ו-routing3 |
| לפי סדר עם תקרה | `routing_count=yes` + `routing_count_1=5` + `routing_count_2=7` | כל נציג מקבל עד N שיחות בו-זמנית, וממשיכים הלאה |
| כל מספר שמקישים | `routing_any_phone=yes` | המתקשר מקיש בעצמו את היעד |

### הגדרות התנהגות

| מפתח | תיאור | ברירת מחדל |
|---|---|---|
| `routing_end_time=20` | זמן המתנה בשניות; אחרי הזמן המאזין "מסיים בשלוחה" | ⚠ ערך ברירת מחדל לא מתועד |
| `routing_end_goto=/8` | "מעבר בסיום" — לאן ממשיכים בסיום הניתוב (מקור: topic/218 + חיפוש "routing_end_goto") | נשאר בשלוחה |
| `routing_your_id=did` | הצגת מספר המערכת כמזהה יוצא | מציג את **מספר המחייג** |
| `routing_your_id=special.0501234567` | זיהוי יוצא במספר מיוחד — חייב להיות מספר **מאושר** במערכת | — |
| `music_on_hold=ztomao` | מוזיקה בהמתנה לחיבור (שם קלאס מוזיקה) | צליל חיוג רגיל |
| `routing_record=no` | ביטול הקלטת השיחה | **הקלטה פעילה** |
| `routing_email_send=yes` | שליחת ההקלטה למייל | לא נשלח |
| `routing_email_address=ddd@gmail.com` | כתובת המייל לקבלת ההקלטות | — |
| `call_no_answer=yes` | לא לשדר "מענה" (=לא להתחיל חיוב) עד שהצד השני עונה | לא |
| `routing_answer_play=yes` | השמעת הודעה בצד המקבל לפני החיבור | לא |
| `routing_answer_tfr=yes` | תפריט לנציג העונה: קבלת השיחה או דחייתה | לא |

### עלות (topic/218)

- routing רגיל: **עלות יחידות לפי דקות, נמדד בשניות**, על רגל השיחה היוצאת.
- `call_no_answer=yes` חוסך חיוב על זמן הצלצול.

## 2. מודול routing_time — הפורמט המלא (post/735)

```ini
type=routing_time
```

פורמט כל נציג — חמישה שדות מופרדים **בנקודה**, `*` = ללא הגבלה:

```
routing_time_X=מספר_טלפון.שעות.ימים_בשבוע.ימים_בחודש.חודשים
```

דוגמאות מהתיעוד:

```ini
routing_time_1=0509111111.09:00-17:00.mon-fri.1-20.jun
routing_time_2=0509029999.*.*.1-20.jun
routing_time_3=0721234567            ; בלי תנאים בכלל = תמיד
routing_time_4=0729876543.*.*.*.*    ; כתיבה מפורשת של "תמיד"
```

- **שעות:** `HH:MM-HH:MM` (למשל `09:00-17:00`).
- **ימים בשבוע:** `sun, mon, tue, wed, thu, fri, sat`; טווח: `mon-fri`.
- **ימים בחודש:** מספרים, טווח `1-20`.
- **חודשים:** `jan, feb, mar, apr, may, jun, jul, aug, sep, oct, nov, dec`.
- כמה שורות `routing_time_X` — נבדקות לפי מי שזמין בזמן השיחה.
- **אין נציג זמין:** מושמעת הודעת מערכת **M1041** — "המענה סגור כעת, אנא נסו
  שוב בשעות הפעילות" — ואז מעבר לפי `close_time_goto=/2`.

| מפתח נוסף | תיאור |
|---|---|
| `close_time_goto=/2` | היעד כשאין נציג זמין |
| `routing_end_time=20` | זמן המתנה (שניות) לפני מעבר |
| `routing_your_id=did` | זיהוי יוצא = מספר המערכת |
| `music_on_hold=ztomao` | מוזיקה בהמתנה |
| `routing_time_record=no` | ביטול הקלטה (שימו לב: **לא** `routing_record` — יש למודול מפתח משלו) |

⚠ כל הזמנים לועזיים. תמיכה בלוח עברי (ערב-שבת, חגים) לא מתועדת ב-routing_time;
לפי-תאריך-עברי יש רק ב-`go_to_folder_date` (קודי S/C/Y — ראו סעיף 6).

## 3. מודול queue (הישן) — הרשימה המלאה (post/60096; שרשור-האם: topic/6076)

שני קבצים בשלוחה: `ext.ini` (הפעלה + מה קורה אחרי) ו-`queue.ini` (נציגים + התור).
עובד מיידית עם ברירות מחדל ברגע ש-`type=queue` מוגדר והנציגים ברשימה.

### queue.ini — נציגים

## 4. מודול routing_queue (החדש) — post/168201 + topic/19229

- `type=routing_queue` — "מבוסס טכנולוגיה שונה" מ-queue, **אותן הגדרות** בערך.
- **עלות:** "המודול כרגע רץ בצורה ניסיונית ולכן אין בו עלות יחידות בחיוג ליעדים
  בישראל עד להודעה חדשה" (topic/19229). ⚠ לבדוק שהמדיניות עדיין בתוקף לפני
  שמסתמכים על "חינם".
- **מגבלה: עד 40 נציגים** (אפשר לפנות לשירות הלקוחות להגדלה).
- מפתחות ייחודיים שהוזכרו בשרשור: `queue_timeout_calls_hangup_max_time=60`,
  קובץ `QueueCallerIds.ini` ופורמט מיפוי `P-[מספר]=` (זיהוי פר-נציג).
- **באגים/פערים שדווחו בשרשור (topic/19229):** מיילים על שיחות יוצאים **ריקים**
  (בלי פרטי שיחה/הקלטה); בקשות להוסיף הקלטות; דיווח שאחרי ניתוק השיחה חוזרת
  לנציג במקום להמשיך לפי `queue_end_continue_goto`; בעיות בהצגת זיהוי קבוע.
  לתרחיש קריטי — לשקול את queue הישן עד שיתוקן.

## 5. ניתוב לפי DID / מחייג — post/60

הכול יושב **בשלוחה הראשית** (`/`), בקובצי ext.ini + `Did_Go_To.ini`:

| מצב | מפתח מפעיל | פורמט שורה ב-Did_Go_To.ini |
|---|---|---|
| לפי המספר **שחויג** | `check_did_and_go_to_folder=yes` | `0773137770=/1` |
| לפי המספר **שחייג** | + `did_directed_check=yes` | `0527666666-Directed-0773137770=/5` |
| מחייג **וגם** מחויג | + `did_and_phone_check=yes` | `0501234567-0773137770=/1` |
| רק בכניסה הראשונה | `check_did_and_go_to_folder_one_time=yes` | — |

- יומן ניסיונות ניתוב: `Log/LogDidDirectedCheck.ini` (לדיבוג "למה לא נותב").
- **בקו האמיתי:** לאחד ה-DID המשניים יש `<המספר>=/555` (הערך ב-yemot-line-state) — הניתוב הזה גובר על `usage=goto:/2` שרשום
  על ה-DID המשני ברמת החשבון (אומת מהתצורה החיה, ראו yemot-line-knowledge).
- ההבדל מ-`routing_to_phone=by_incoming_did` (סעיף 1): Did_Go_To.ini מנתב
  ל**שלוחה**; RoutingIncomingDID.ini מנתב ל**מספר טלפון** מתוך מודול routing.

## 6. מעבר תיקיות לפי זמן — post/56, post/57

### type=go_to_folder_time (post/56)

```
go_to_folder_time_X=תיקיה.שעות.ימים_בשבוע.ימים_בחודש.חודשים
```

- אותו אוצר-ערכים כמו routing_time (שעות `09:00-17:00`, ימים `mon-fri`,
  ימים-בחודש `11-18`, חודשים `jan-dec`, `*` = הכל).
- אין שורה תואמת לזמן הנוכחי → הודעה **M1962** ואז `go_to_folder_time_error_goto=/3`.
- ההבדל מ-routing_time: כאן היעד הוא **תיקייה/שלוחה**, לא מספר טלפון — ואין עלות.

### type=go_to_folder_date (post/57)

`go_to_folder_date=` + רצף קודי-אות **רגישי רישיות** שמרכיבים את שם תיקיית היעד:

| קוד | משמעות | דוגמה |
|---|---|---|
| `y` | שנה לועזית | 2022 |
| `m` | חודש לועזי | 12 |
| `d` | יום לועזי | 29 |
| `S` | שנה עברית | 5782 |
| `C` | חודש עברי | 01 |
| `Y` | יום עברי | 12 |
| `h` | שעה נוכחית | 0–23 |
| `M` | דקות | — |
| `s` | שניות | — |
| `U` | יום בשבוע | 1–7 (ראשון–שבת) |

- `go_to_folder_date=ymd` → תיקייה בשם `20170126`; `go_to_folder_date=h` →
  תיקייה לפי השעה.
- שגיאה (אין תיקייה כזו) → `go_to_folder_date_error_goto=/5/8`.
- **זה המנגנון המתועד היחיד לניתוב לפי לוח עברי** (S/C/Y).

## 7. CreateBridgeCall — שיחת גישור מה-API (post/72304)

המערכת מחייגת ל-`Phones`; כשעונים — מגשרת אל `BridgePhones`.

| פרמטר | סוג | תיאור | ברירת מחדל |
|---|---|---|---|
| `token` | string | טוקן (אצלנו: `מספר:סיסמה` כמו בכל yemot._call) | — |
| `callerId` | string | הזיהוי שמוצג לשני הצדדים | מספר המערכת הראשי |
| `Phones` | string | המספר שמחויג ראשון | — |
| `BridgePhones` | string | המספר שאליו מגשרים | — |
| `DialSip` | 0/1 | חיוג דרך חשבון SIP | 0 |
| `DialSipExtension` | 0/1 | חיוג דרך שלוחת SIP | 0 |
| `AccountNumber` | int | מספר חשבון SIP (ברירת מחדל: הראשי) | — |
| `SipExtension` | int | שלוחת ה-SIP | — |
| `RecordCall` | 0/1 | הקלטת השיחה | 0 |
| `SendMailInCall` | 0/1 | שליחת ההקלטה במייל בסיום | 0 |
| `SendMailInCallTo` | string | נמען ספציפי להקלטה | — |

- **עלות:** "0.1 יחידות על עצם הפעלת הקמפיין" + חיוב לפי משך: זמן שיחת הנציג +
  זמן הדיבור של הלקוח (זמן החיוג אל הלקוח לא נספר).
- **תשובה מוצלחת:** `responseStatus`, `CampaignId`, `callerId`, `callsCount`,
  `bilingPerCall`, `biling` (כן, באיות הזה — bilin g בלי שני l), `RecordCall`,
  `SendMailInCall`, `SendMailInCallTo`.
- ⚠ טרם אומת בשטח על הקו שלנו (09/2026). לשימוש: `yemot._call("CreateBridgeCall", {...}, post=True)`.

## 8. Click To Call — post/99426

- תוסף כרום רשמי (חנות התוספים): לחיצה על מספר בדפדפן → המערכת מחייגת **אליך**,
  וכשאתה עונה מחייגת ליעד.
- **התחברות:** מגרסה 1.4.1 — **API Key בלבד** (מפיקים בממשק הניהול), בלי מספר
  מערכת/סיסמה בתוסף.
- **עלות:** 0.1 יחידה להפעלת כל שיחה + דקות השיחה הנכנסת אליך (חינם אם אתה על
  חשבון SIP) + דקות השיחה היוצאת ליעד. כלומר: טלפון אישי = 3 רכיבי חיוב, SIP = 2.
- **אבטחה:** המפתח נשמר מקומית בדפדפן — מי שניגש לדפדפן יכול לחלץ אותו; ביטול
  ה-API Key מנטרל את התוסף מיד.

## 9. שאלות פתוחות (⚠ טרם אומת)

- ברירת המחדל המספרית של `routing_end_time` כשלא הוגדר — לא מתועדת.
- התנהגות **תפוס** ביעד של routing רגיל (מה שומע המתקשר; האם עוברים ל-
  `routing_end_goto` מיד) — הוזכר בפורום צליל-תפוס בהמתנה (topic/21077) אך לא
