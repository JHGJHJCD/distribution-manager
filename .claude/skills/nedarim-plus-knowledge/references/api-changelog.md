# נדרים פלוס — "מה חדש בתיעוד ה-API"

יומן שינויי-חוזה, פעולות חדשות ותיקוני-תיעוד של ה-API (מסך `עוד > API > מה חדש בתיעוד`).
נשמר כמקור. עודכן לאחרונה מהמשתמש: 31/08/2026. הפרמטרים המדויקים → [`api-full.md`](api-full.md).

## 30/08/2026
- **`SendSms` נפתחה לכל המוסדות** — הייתה חסומה בפועל (דרשה אימות טלפוני שכבר לא קיים). שער הוסר.
  - `Message` עד 804 תווים (4 יחידות × 201); `Phone` = נמען אחד/רשימה (פסיק/שורה).
  - `AllowError` (ברירת מחדל true): מדלג על שגוי; false = הכל-או-כלום ומצביע על הבעייתי.
  - סינון אוטומטי: לא-תקין / כפול / **קו כשר** (קידומת). עד 5,000/קריאה, 10,000/יממה.
  - תשובה `"שודרו בהצלחה N סמסים"`. **מפתח מוגבל צריך הרשאת "שליחת SMS" (קטגוריה מתקדם).**

## 27/08/2026
- **`ApiValid` (אימות אייפרם) אינו נעול** — ערך שגוי מחזיר שגיאה בלבד; אין מונה/נעילה/חסימת-IP.
  **חסימת ה-IP לשעה אחרי 10 שגויים חלה רק על `ApiPassword`.**
- בדיקת חיבור בלי להקים עסקה: `CreateTransaction` עם `Amount=0`.
- עסקה שהוקמה ב-`CreateTransaction` ולא הושלמה = שורת-הכנה בלבד (לא חיוב, לא בהיסטוריה, בלי Callback).
- **`GetMosad` — קריאה ציבורית בלי מפתח/סיסמה** לאמצעי-התשלום הפעילים למוסד (PayBt, Bit,
  DigitalTransfer, Finovo, Masav, Dollar, שדות-חובה, קטגוריות). **מוגבל-קצב פר-IP/מוסד — לשמור בצד.**

## 26/08/2026
- אייפרם: `StartFrom` ב-`FinishTransaction2` — תאריך-חיוב-ראשון מלא להו"ק (חוזר ב-`NextDate`).
  חיוב מיידי + הו"ק בהזנת-כרטיס אחת = שתי `FinishTransaction2` ברצף.

## 25/08/2026
- **`CreateKevaUpdateLink`** — קישור אישי לתורם לעדכון כרטיס אחרי סירוב (מספר-הכרטיס לא עובר בשרת שלנו);
  קריאה חוזרת מחזירה קישור קיים בתוקף. **`GetKevaUpdateLinkStatus`** — Views/Used/UsedDate/Expired.
  שליחת המייל הממותג נשארת בממשק; אין ביטול-קישור מה-API.
- אייפרם: `AuthorisationNumber` ב-`TransactionResponse` (הו"ק) = אישור-חברת-אשראי על ההקמה
  (החיוב הראשון בעדכון נפרד עד ~3 שעות). כרטיסי-בדיקה עובדים במוסד `0` בלבד; אין SANDBOX שוטף.
  יצירת/חיוב טוקן — באישור פרטני של נדרים לפני פיתוח.
- **קישור מהיר ללקוח ליצירת מפתח API** (בונה-קישורים; `*`=מלא דורש אישור-בהקלדה; מומלץ `AllowedIPs`).
- **`DoubleKevaNew`** — שכפול הו"ק אשראי מאותו כרטיס (מחזיר `KevaId` חדש) → אז `UpdateKevaNew`.
