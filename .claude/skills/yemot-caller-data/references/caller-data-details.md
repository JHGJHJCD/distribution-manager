# פירוט גולמי — נתונים אישיים ואיסוף מידע מהמתקשר (ימות המשיח)

חומר הגלם המלא שנאסף מתיעוד הפורום הרשמי f2.freeivr.co.il ב-01/09/2026.
התמצית האופרטיבית — ב-`SKILL.md`. כל סעיף כאן מציין את הפוסט שממנו נלקח.

## 1. id_message — הודעה אישית אחת לכל מזוהה (post/50)

- `type=id_message` — המערכת מחפשת קובץ שמע ששמו **בדיוק** מספר הזיהוי של
  המתקשר: זיהוי טלפון `0548594142` → הקובץ `0548594142.wav`; זיהוי ת"ז
  `0123456789` → `0123456789.wav`.
- אין קובץ מתאים → מושמעת הודעת מערכת **M1099** ("אין הודעה להשמעה").
- ניתוב:
  ```ini
  id_message_end_goto=1/1      ; לאן ממשיכים אחרי השמעה מוצלחת
  id_message_error_goto=/2/1   ; לאן בשגיאה (למשל אין קובץ)
  ```
- **כניסה עם זיהוי היא חובה** במודול (enter_id — ראו סקיל yemot-enter-id).

## 2. id_list_message — שרשרת תכנים אישית מקובץ נתונים (post/50)

- `type=id_list_message` + קובץ הנתונים **`IdListMessage.ini`** בשלוחה.
- הגדרות שתועדו בפוסט:
  ```ini
  id_list_message_file=/1                  ; מיקום (שלוחה) של הקובץ/קבצי-השמע — ⚠ הסמנטיקה המדויקת לא אומתה בשטח
  id_list_message_no_message_goto=/1       ; אין רשומה למתקשר → לאן
  id_list_message_end_goto=/1              ; אחרי השמעה → לאן
  id_list_message_date_say_month_number=yes ; בתאריכים — להקריא את מספר החודש
  play_and_return=play_all
  id_list_message_save_log=yes             ; לוג השמעות
  ```
- מבנה שורה בקובץ: `מספר_זיהוי=סוג-ערך.סוג-ערך.סוג-ערך` — **המפריד בין
  פריטים הוא נקודה (`.`)**. שורת `default=סוג-ערך` = מה שישמע מי שאין לו רשומה.
- דוגמה מהפוסט:
  ```
  0533137770=f-57750730.f-57881001.a-www012@.d-5567.n-5123
  ```

### קידומות הסוגים (כולן מ-post/50)

| קידומת | דוגמה | מה מושמע |
|---|---|---|
| `f-` | `f-error` | קובץ שמע (בלי סיומת; נלקח מהשלוחה הנוכחית אא"כ הוגדר אחרת) |
| `d-` | `d-123` | ספרות: "אחת שתיים שלוש" |
| `n-` | `n-123` | מספר: "מאה עשרים ושלוש" |
| `a-` | `a-abc` | אותיות/תווים אחד-אחד (גם לטיניות וסימנים) |
| `t-` | `t-שלום עולם` | טקסט חופשי ב-TTS |
| `s-` | `s-123` | ⚠ "Speech" — לא ברור ההבדל מ-t-/n-; לא אומת |
| `h-` | `h-music_name,5` | מוזיקה בהמתנה, אופציונלית עם הגבלת דקות |
| `date-` | `date-01/01/2019` | תאריך לועזי מוקרא |
| `dateH-` | `dateH-01/01/2019` | התאריך מומר ומוקרא **עברי** |
| `z-` | `z-sunset,IL/Jerusalem,-,m20,1` | זמני היום (זריחה/שקיעה עם היסט) |
| `m-` | `m-1001` | הודעת מערכת לפי מספרה |
| `g-` | `g-/1/2/3` | ניתוב לשלוחה — **חייב להיות אחרון** |

### מלכודות מהפוסט
- בתוך `t-` (טקסט) **אסור** להכניס נקודה (`.`) או מקף (`-`) — אלו תווי-בקרה
  של הפורמט.
- אחרי `g-` (ניתוב) אי אפשר לשרשר פריטים נוספים.
- קבצי שמע (`f-`) נלקחים מהשלוחה הנוכחית אלא אם הוגדר אחרת.
- קידוד הקובץ: UTF-8 (כמו כל קובצי הנתונים בעברית; ראו גם
  ListAllInformation.ini בסקיל yemot-enter-id).

## 3. סקר ישן — type=seker (post/100)

```ini
type=seker
allow_unlisted_number=yes    ; גם חסויים עונים, ואותו מספר יכול להצביע שוב
change_selection=yes         ; מצביע יכול לשנות את בחירתו
key_ok_0=0                   ; ... עד key_ok_9=9 — אילו מקשים פתוחים להצבעה
seker_end_goto=/1
seker_email_address=aaa@aaa.aaa
seker_email_name=אברהם
```
- **תוצאות בזמן אמת:** אחרי הצבעה המתקשר שומע כמה השתתפו ואחוזים לכל אפשרות.
- **דוח למנהל:** תפריט הניהול הטלפוני → הקשה 1 → מספר השלוחה + `#` →
  הודעה M2733 → הקשה 1 שולחת את הדוח למייל שהוגדר.
- `seker.ini` — עמודות דוח הסיכום (Folder, DID, Selekt0–Selekt9 באחוזים);
  `seker_log.ini` — עמודות דוח הפירוט (Phone, Date, Selekt).
  ⚠ בפוסט הם מוצגים כקובצי-תבנית לכותרות העמודות (כמו coupon_log.ini) — לא
  אומת אם הם גם קובצי האחסון עצמם.

## 4. סקר חדש — seker_questions (post/13236)

- ריבוי שאלות בסקר אחד; כל שאלה בתיקייה ממוספרת עם קובץ **`Q.wav`**.
- הגדרות שתועדו:
  ```ini
  seker_questions_patch=1        ; באיזו שלוחה יושבות השאלות (⚠ איות "patch" כפי שבפוסט)
  seker_questions_numbers=1.2.8  ; אילו שאלות פעילות (מופרד בנקודות)
  say_q_number=no                ; לבטל את הכרזת "שאלה מספר X"
  seker_questions_log_file_type=day   ; פיצול דוח לפי יום (או month)
  say_results=all                ; all / percentage / amount / nothing
  seker_questions_add_record_converted_to_text=yes  ; הקלטת המתקשר בסוף + STT
  ```
- ברירת המחדל לתזמון ההקלטה: `2-2-20` (שקט, מינימום, מקסימום שניות).
- דוחות: כללי `seker_questions_log.ymgr`; פר-שאלה `Q_log.ymgr` בתוך תיקיית
  כל שאלה.
- יש הגבלת-זמן לסקר עם הכרזות ספירה-לאחור, ו"ניהול טלפוני" מלא של הסקר.

## 5. recording_and_entering_data — הקלטות + נתונים בשיחה אחת (post/36372)

- `type=recording_and_entering_data`. מסלול-שיחה משולב: המתקשר גם **מקליט**
  וגם **מקיש נתונים** — הכל נשמר כרשומת אישור אחת.
- קבצי-ההנחיה (הפרומפטים) בשלוחה: **000–049 = שלבי הקלטה** של המתקשר,
  **050–099 = שלבי הקשת נתונים**. סדר ברירת המחדל: קודם הקלטות ואז נתונים;
  היפוך עם `start_first=data`.
- `recording_and_entering_data_folder_to_play=/8` — להשמיע פרומפטים משלוחה אחרת.
- קבצים שנוצרים בשלוחה:
  - `ApprovalAll.ymgr` / `ApprovalAll.html` — רשומות ההשלמה (מי סיים, מה הקיש).
  - תיקיית `Record/` — ההקלטות שנאספו.
  - `LogRecordingAndEnteringData.html` — לוג פעילות מפורט.
  - `ApprovalNumberNow.ini` — מונה מספרי האישור (הועבר מ-ext.ini כדי למנוע
    התנגשויות כתיבה).
- יכולות נוספות שתועדו: מגבלות הקלטה (שקט/אורך), ולידציה ומניעת כפילויות,
  שילוב תשלום, אישור ב-SMS/מייל, תקרת נרשמים (`booking_max=1250`), מספרי
  אישור מותאמים מקובץ חיצוני.
- אזהרה מהפוסט: לא לשים תווים עבריים בנתיבי ניתוב כשמשתמשים בשליחת מייל.
- **בקו שלנו:** שלוחה 11 מכילה `;type=recording_and_entering_data` **מוער** —
  המודול לא פעיל שם (ראו yemot-line-knowledge).

## 6. המרת דיבור לטקסט — stt_dir_all_file (post/134)

- `type=stt_dir_all_file` — המרה בכמות של כל קובצי השמע בתיקייה לטקסט.
- בכניסה לשלוחה: "יש לך X קבצים להמרה — 1 לאישור, 2 לביטול".
- `stt_dir_all_file_dir=/5/8` — תיקיית יעד אחרת (ברירת מחדל: השלוחה הנוכחית).
- אחרי המרה הקבצים ממוינים לתתי-תיקיות: `OK` (הצליח), `ERROR` (נכשל),
  `NO_RESULT` (בד"כ קובץ ריק).
- נוצר `LogSttDirAllFile.html` בתיקיית היעד — שם קובץ + הטקסט המתומלל.
- העלות = תעריף המרת-טקסט הרגיל של ימות (לא פורט בפוסט). עדכון אחרון של
  הפוסט: 22/03/2022.

## 7. קופונים — type=coupon (post/86)

- קובץ **`coupon.ini`**: שורה = `מספר=קוד`, למשל:
  ```
  1001=erty
  1002=vgii
  ```
- ```ini
  type=coupon
  coupon_start=0        ; מאיזה מספר מתחילים (ברירת מחדל 1000)
  coupon_max=1040       ; הקופון האחרון
  coupon_sey_tts=yes    ; הקראת קוד עם עברית ב-TTS (⚠ האיות "sey" — כך בפוסט)
  emeil_send=yes        ; שליחת רשומת הקופון למייל (⚠ האיות "emeil" — כך בפוסט)
  coupon_end_goto=/8
  ```
- הודעות מערכת: M1015 מתקשר לא מזוהה · M1414 נגמרו הקופונים · M1415 אישור
  מסירת קופון. רק מזוהים נכנסים לשלוחה.
- מייל: `CustomerEmail`/`CustomerName` הגלובליים, עם דריסה מקומית
  `email_address`/`email_name`. `coupon_log.ini` = כותרות עמודות הדוח.

## 8. מספרי אישור — approval_number (post/87)

- מודול "חלוקת אישורים": כל מתקשר מזוהה מקבל מספר אישור רץ.
- ברירת מחדל: המספור מתאפס בחצות; `approval_number_type=always` = מונה רציף.
- נשמר ב-`ApprovalNumberNow.ini`; מייל עם `email_send=yes`; דוח HTML עם
  עמודות שאפשר להסתיר; תקרת אישורים לאדם; אישורים מיוחדים מקובץ; שליטה אם
  המספר מוקרא למתקשר; ניתוב שגיאות. M1015 ללא-מזוהים.
- ⚠ שורת ה-`type=` המדויקת לא חולצה מילה-במילה מהפוסט (ככל הנראה
  `type=approval_number` לפי קידומות ההגדרות) — לאמת לפני שימוש.

## 9. חלוקת קודים — type=codes (post/78103)

- קובץ **`Codes.ini`** — קוד בכל שורה:
  ```
  1234
  5678
  ```
- המתקשר מקיש קוד מהרשימה, או מבקש **קוד אקראי** (הקשה 2) — שימושי להגרלות.
- `codes_enter_id_max` — כמה קודים מקבל כל משתמש · `min_digits_codes` /
  `max_digits_codes` — אורך הקוד · `codes_menu_first=yes` — התפריט (הקשה
  חוזרת/אקראי/יציאה) מושמע כבר בכניסה.
- מעקב: `CodesTaken.ymgr` + `CodesTaken.html` — טלפון, זמן, הקוד שחולק.

## 10. השמעת מספר המתקשר — say_dialing_number (post/67226)

- `type=say_dialing_number` — אחרי הודעת הפתיחה המערכת מקריאה למתקשר את
  **המספר שממנו הוא מתקשר**. חסוי/שגיאה → M1080.
- `say_dialing_number_end_goto=/1` · `say_dialing_number_error_goto=/2`;
  בלי goto — חוזר רמה אחת למעלה.

## 11. דיווח יומי על משימות — tasks_report (post/63)

- `type=tasks_report` + קובץ **`task_desc_status_phone.ini`** — משימות
  משויכות למספרי טלפון; המתקשר שומע את משימותיו ומדווח ביצוע.
- `reporting_folder=/1/reports` · `date=hebrew` (תאריך עברי/לועזי בדוחות) ·
  `set_ok_send_mail=yes` (דוח HTML יומי במייל) · `WhiteList.ini` אופציונלי
  להגבלת גישה.
- 4 תתי-מצבים של שלוחות: דיווח אישי · משימות שלא הושלמו · דוח יומי במייל ·
  דוחות היסטוריים. הודעות מערכת M2160–M2167.
