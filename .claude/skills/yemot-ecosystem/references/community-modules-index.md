# אינדקס המודולים הקהילתיים של ימות (מקור: f2 topic/14490)

קטלוג ה**מודולים הקהילתיים** (`type=api` — שלוחה שקוראת לשרת חיצוני בזמן שיחה)
ותוכנות-העזר שהקהילה בנתה ושיתפה בפורום הרשמי. זו **שכבה C** של האקוסיסטם
(ראה SKILL.md §3–4). **לפני שכותבים מודול/כלי מאפס — לחפש כאן קודם.**

- מקור: `https://f2.freeivr.co.il/topic/14490/` ("אינדקס המודולים המלא של API")
- אינדקס-קישורים כללי נוסף בפורום: `/post/26449`
- הערות ותגובות על האינדקס: `/topic/14491`
- נמשך ונותח 09/09/2026. הרשימה משקפת את מה שהיה בדף באותו יום; מודולים חדשים
  נוספים שם מעת לעת — לרענן מהמקור בעת הצורך.

⚠ **כל אלה קוד של מפתחים פרטיים, לא של ימות.** רובם דורשים שרת ביניים (webhook)
או קובץ PHP שהיוצר מארח. לא לאמץ מודול לפני שמבינים לאן ה-`api_link` פונה
ומי מחזיק את השרת. חלק מהקישורים ישנים/מתים.

⚠⚠ **~90% מהמודולים ברשימה כבר לא פעילים** (הבהרת @שולי בשרשור התגובות
topic/14491) — הערך העיקרי כאן הוא **השראה ודפוס-מימוש** ("איך אנשים בנו X"),
לא כלי מוכן להפעלה. לפני הסתמכות על מודול — לוודא שהשרת שלו עדיין חי.

🔒 **אבטחה** (הבהרת @דוד_מלך_ישראל): עצם השימוש במודול `type=api` **לא** נותן
למפתח גישה למערכת שלך — השלוחה רק שולחת בקשת HTTP לשרתו ומקבלת פקודות.
מה **שכן** נותן גישה = הכנסת **סיסמת/טוקן המערכת** לתוך כלי צד-שלישי (שכבה B).
לכן: מודול API = לבדוק לאן ה-webhook פונה; כלי-ניהול = לתת סיסמה רק לגורם נאמן.

## ⭐ מודול חי ומתוחזק: ניהול רשימת צינתוקים מתקדם (@CUBASE, topic/21774)

**חריג ל-"90% מתים"** — מודול `type=api` פעיל (פורסם 08/2026), ורלוונטי ישירות
אלינו: הוא מאוחסן על **Cloudflare Worker** (`moduls.smartel.workers.dev`) —
**אותה תשתית כמו שרת המענה /76 שלנו**. שווה ללמוד ממנו כדפוס מימוש.

מה הוא נותן מעבר לשלוחת-הצינתוקים המובנית: השמעת כמות **מוזמנים שטרם אישרו**
(לא רק פעילים/מושתקים), בחירת רשימה דינמית בטלפון, האזנה לכל הרשומים עם
שם+סטטוס (פעיל/חסום/הוזמן), ו**לוג פעולות מפורט** (סוג פעולה: הוספה/הסרה/
חסימה/זימון/ביצוע-צינתוק; תאריך+שעה, השלוחה, מי ביצע ועל מי).

**דפוס ה-`type=api` שכדאי לאמץ** — הגדרת פרמטרים לשרת דרך `api_add_X`:
```ini
type=api
api_link=https://moduls.smartel.workers.dev/tzintukStatus.php
api_add_0=token=YOUR_API_TOKEN
api_add_1=use_tts=yes            ; כשאין קובצי שמע — הקראה ב-TTS
api_add_2=list_tzintuk=123       ; רשימה קבועה מראש (אחרת תפריט בחירה)
api_add_3=display_mode=numbers_only | log_only
api_add_4=say_summary=no
api_add_5=menu_option_1=3        ; שיבוץ מקשי התפריט (noop לביטול)
```
ניווט: 10 פריטים בעימוד, `0`=הבאים, `*`=אחורה/לתחילת השלוחה. משתמש בהודעות
מערכת M מובנות (M4108/M4109 = כמות פעילים/מושתקים, M1483/M1485 = בתאריך/בשעה,
M1347 = אין נתונים) + קבצי `S` מותאמים ב-`/Smartel/Messages/` (S1053 = מוזמנים
שטרם אישרו, S1065–S1076 = תיאורי סוגי-הפעולה ללוג).

💡 **תובנות לנו:** (1) `api_add_X=key=value` = הדרך להעביר קונפיג לשרת שלנו
בשלוחת type=api. (2) מושג ה"מוזמן שטרם אישר" = דפוס opt-in לרשימת צינתוקים.
(3) לוג-פעולות פר-רשימה = רעיון לתיעוד. (4) חלופה מוכנה אם אי-פעם נרצה
שהמאזין ישמע/ינהל את רשימת הצינתוקים מהטלפון.

## 🧠 קומבינה: חיוג-יוצא בזיהוי מספר המערכת בחינם (@CUBASE, topic/21248)

טריק לניצול הצינתוק (חינם) כדי לחייג החוצה עם מספר המערכת כ-caller-id, אחרי
שימות חסמו את "המספר הנוסף" והתחילו לגבות על "ראוטינג תור". **לא נחוץ לתוכנה
שלנו** (הצינתוקים שלנו כבר מציגים את מספר הקופה), אבל מתעד מפתחות שימושיים
ומאשש את מנגנון ה-DID של /76:
```ini
; שורש: DID → שלוחת System
check_did_and_go_to_folder=yes
check_did_and_go_to_folder_one_check_only_phone=yes   ; וריאנט: בדיקת טלפון בלבד
; Did_Go_To.ini:  <מספר-המערכת>=System

; שלוחת חיוג (type=tzintuk)
type=tzintuk
list_tzintuk=system
tzintuk_admin=yes
run_tzintuk_automat=yes
tzintuk_say_system_info_on_answer=yes   ; ⚠ המפתח שמאפשר מענה (אצלנו אסור בקלאסי)
tzintuk_invitation_join_to_list_caller_id=customer_did   ; בהכנת הרישום
tzintuk_end=hangup

; יעד (type=nitoviya) — חיוג החוצה
type=nitoviya
nitoviya_dial_to=05XXXXXXXX
send_dtmf=1,0010,0100                    ; הקשות-אישור אוטומטיות
; access_filter=g.*.*.*.*.*.8s.1.thiscall  לניתוב חד-פעמי
```
רעיון הזרימה: מתקשרים לשלוחה → המערכת מנתקת ומצנתקת בחזרה → עונים, מקישים
יעד → ניתוביה מחייגת עם מספר המערכת. טאצ': להשתיק M3338 בקובץ שקט.

## שימושון ext.ini למתקדמים (topic/8332) — מפתחות אמיתיים

"שימושון כללי למשתמשים מתקדמים" (@שמחה, 2022, מוצמד) — ריכוז **מפתחות ext.ini
פופולריים** למי שכבר יודע מה כל אחד עושה (במפורש: לא נועד להסברים). כולל קבצי
`ini`/`tts` להורדה. ⚠ זו רשימת-עזר קהילתית — **התחביר הסמכותי נשאר התיעוד
הרשמי / סכמת ה-MCP החיה** (כתיבה ל-ext.ini רק עם `provenance=yemot_documentation`).
להלן המפתחות כפי שמופיעים שם, עם דגש על מה שנוגע לנו:

### 🎯 שרת המענה /76 שלנו — המפתחות המדויקים
```ini
; ניתוב לפי DID (זה מה שיש בשורש הקו שלנו — Did_Go_To.ini)
check_did_and_go_to_folder=yes
check_did_and_go_to_folder_one_time=yes
; קובץ הניתוב: Did_Go_To

; השמעת הודעת הקמפיין למי שחוזר לקו + מחיקה
play_campaign_message=yes
play_campaign_message_one_time=yes
campaign_message_to_play=3-ACTIVE-2,1--5,6,9-ACTIVE,7-BLOCKED,8-NONE,10-ERROR,15--1-30s,13--1-1m,16--1-1h,12--1-1d,14--1-1M
campaign_selection_by_id_from_folder=/1/1
campaign_message_to_play_file_by_template=yes
campaign_message_delete_file_template_number=default/מספר קמפיין
campaign_message_to_play_file_from_folder=/1
```
המיפוי: מקש-ACTIVE/BLOCKED/NONE/ERROR + חלונות-זמן (30s/1m/1h/1d/1M) — בדיוק
מנגנון "מה שומע מי שחוזר" של /76. (השדה `campaign_message_to_play` = מיקום 17.)

### 🎯 סקר /77 שלנו — recording_and_entering_data
```ini
type=recording_and_entering_data
start_first=data
001-option=6-40-STT-TTS-ask
050-option=10-9--HebrewKeyboard---CheckGoTo-   ; ⚠ מפתח דינמי שפתרונאי משמיט
say_approval_number=say_approval_no_number
recording_and_entering_data_end_goto=/8
add_to_list_all_information=yes
add_enter_id_to_list_all_information=yes
add_approval_1_to_list_all_information=yes
add_enter_id_to_list_all_information_change=yes
```

### צינתוק ורשימות תפוצה
```ini
type=tzintuk                     ; שלוחת צינתוק
list_tzintuk=123
tzintuk_admin=yes
run_tzintuk_automat=yes
tzintuk_end=/1

type=yemot_dialer_campaign_start ; הפעלת קמפיין
template_to_start=2

type=template_remove_number      ; הסרה מרשימת תפוצה
template_to_remove=2
remove_and_delete=yes
template_remove_no_ask=yes
```

### זיהוי, פילטר, ניתוב, הודעות אישיות

```ini
; זיהוי מתקשר

; אקסס-פילטר (הרשאה לפי קריטריונים; g.<שעות>.*.*.*.<שנים>.<דקות>...)

access_filter_2=g.00:00-07:00.*.*.*.2014-2015.20m.7.5d

type=add_id_to_list

```
