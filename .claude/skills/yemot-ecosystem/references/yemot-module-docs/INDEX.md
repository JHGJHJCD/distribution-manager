# תיעוד מודולי ימות המשיח — אוסף מסודר (offline)

מראה מלאה של תיעוד מודולי ימות, מסודר ב-28 קטגוריות (160 מסמכי `.txt`).
רמת תיעוד רשמית — **התחביר המדויק של ext.ini לכל פיצ'ר**. מקור: אוסף
"אזור התעשייה" שיהודה הוריד (09/09/2026). זה המקור המהימן ביותר שיש לנו
למודולי ימות — **לחפש כאן (grep) לפני שכותבים/מדמים שלוחה**.

## הכי רלוונטי למנהל-חלוקה (צינתוקים / /76 / /77)
- **`קבלת נתונים/קבלת הקלטות ונתונים - recording_and_entering_data.txt`** —
  מנגנון הסקר /77 שלנו במלואו (1896 שורות): ערכי `050-option` (18 פרמטרים,
  כולל `CheckGoTo` וניתוב מותנה), `add_to_list_all_information`,
  `add_approval_1/date/time/phone/extension`, `set_temp_to_log`. **המפתח
  הדינמי שפתרונאי משמיט — כאן מתועד במלואו.**
- **`API/קמפיין הודעות אישיות בAPI...txt`** — המנגנון של /76 (מי שחוזר שומע
  הודעה אישית). ימות מוכרים אותו בתשלום; ה-Cloudflare Worker שלנו עושה חינם.
  כולל `withSMS=1` (כשר→שיחה, לא-כשר→SMS) ו-`ttsMode=1` עם הודעה למספר.
- **`API/מודול API - תקשור עם מחשבים...txt`** — type=api (השרת שלנו).
- **`קמפיינים ורשי''ת/`** — הוספה/הסרה/חסימה מרשימות, **הזמנת חבר (opt-in)**,
  השמעת הודעת קמפיין בכניסה, בדיקה אם מספר קיים.
- **`השמעת הודעות ונתונים/...id_message id_list_...txt`** — נתון אישי למתקשר.
- **`פילטרים ומעברים/`** — `access_filter`, פילטר לפי רשימות צינתוקים/תפוצה.
- **`כללי/כל סוגי השלוחות הקיימות.txt`**, `יצירת קובץ ini.txt`,
  `קובץ שקט תקין להחלפת הודעות מערכת.txt`, `דוחות ymgr html ו-csv.txt`.

## דרך חיפוש
`grep -ril "<מפתח או מילה>" .` מהתיקייה הזו (הכל UTF-8). שמות הקבצים בעברית
מקוצרים לפעמים באמצע מילה (חיתוך מקורי של האוסף) — לחפש בתוכן, לא רק בשם.
