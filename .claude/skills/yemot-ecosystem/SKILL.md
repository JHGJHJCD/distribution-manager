# האקוסיסטם של ימות המשיח — מה מתחבר לקו ומה זה נותן

"תוסף" בימות המשיח הוא לא חנות-תוספים רשמית. יש **שלוש שכבות** של הרחבה,
וכל בקשה "יש משהו שעושה X?" צריך למקם באחת מהן:

| שכבה | מי מספק | איך זה מתחבר | דוגמאות |
|---|---|---|---|
| **A. מודולים רשמיים** | ימות עצמם (בתשלום / לפי יחידות) | הגדרת `type=` בשלוחה או שירות שמופעל בקו ע"י ימות | מכירות, תורים, סקרים, ועידות, SMS, סליקה |
| **B. כלי-ניהול צד-שלישי** | מפתחים פרטיים | מתחברים עם **סיסמת הקו / טוקן API** ל-`call2all.co.il/ym/api` | פתרונאי (pitronai), ממשק ה-BETA של ימות, YemotSMSInbox |
| **C. הקוד שלך** | אתה | (1) **API חיצוני** — אתה קורא לשרת ימות (ניהול, קמפיינים, קבצים); (2) **מודול API** — שלוחת `type=api` קוראת **לשרת שלך** בזמן שיחה חיה | `utils/yemot.py` שלנו, yemot-router2, yemot-otp |

שני כיווני ה-API של שכבה C הם **מנגנונים שונים לגמרי** (f2 post/75: "אין קשר
בין API זה למודול ה-API"). ספרייה שמתאימה לאחד לא בהכרח מכסה את השני —
ראו את הטבלה בסעיף 3. פירוט המודול-בשלוחה: סקיל `yemot-api-module`;
ה-API החיצוני: סקיל הענן `anthropic-skills:yemot-hamashiach`.

## 1. שכבה A — מודולים ושירותים רשמיים של ימות (yemot.co.il)

מה שימות מוכרים כ"מערכות" (רובן = שלוחות מסוגים מיוחדים + ממשק ניהול,
חלקן דורשות הפעלה מול השירות):

- **מערכת מכירות** — קטלוג מוצרים, הזמנה בטלפון 24/7, דוחות, סניפים/ספקים.
- **מערכת ניהול תורים** (`queue.call2all.co.il`, של SHMM) — נציגים, המתנה,
  דוחות (ב-MCP: `queue_*`, `plan_queue_agents_update`).
- **ביצוע סקרים** — שאלונים רב-משתתפים, ניתוב חכם, המרת דיבור לטקסט.
  ⚠ אצלנו הסקר (שלוחה 77) בנוי על `recording_and_entering_data` הרגילה —
  לא על המודול בתשלום (סקיל `yemot-caller-data`).
- **הודעות קוליות / קמפיינים** — זה ה-RunCampaign/צינתוק שאנחנו משתמשים בו.
- **טיקטפון** — מכירת כרטיסים (אתר + טלפון מסונכרנים).
- **קבוצות חברתיות** — הודעות קבוצתיות עם שליטת מנהל.
- **בתי ספר ומוסדות** — רישום, ציונים ונתונים אישיים למתקשר.
- **חדרי ועידה ושידור חי** — כולל מעקב נוכחות ומשוב מאזינים.
- **מערכות רישום** לאירועים/קורסים עם תשלום.
- **סליקת אשראי ותרומות** — אינטגרציה מובנית עם פלאקארד, טרנזילה, קארדקום,
  קרדיט-גארד, iCredit (f2 topic/56). ⚠ **נדרים פלוס לא ברשימה** — אצלנו
  הוא מתוכנן דרך API חיצוני (סקיל `nedarim-plus-knowledge`).
- **SMS ופקס** יוצאים (ב-MCP: `send_sms`, `send_fax`), **1900** (תוכן בתשלום),
  **פרסומפון** (פרסומות אודיו), **מספרים בינלאומיים** ו"מספר וירטואלי",
  **קריינות** מקצועית, **המרת הודעה קולית לטקסט**.
- **ממשק ניהול חדש רשמי (BETA):** `call2all.co.il/yemot-admin-g1/` —
  SPA שנטען דינמית; לא נבדק לעומק (03/09/2026).

## 2. שכבה B — כלי-ניהול צד-שלישי

### פתרונאי / Pitron AI (`ivr.pitronai.com`) — **הכלי שאנחנו מחוברים אליו**
פיתוח פרטי, **לא של ימות**, **חינמי** (בטא). אתר-ניהול מונגש לקווי ימות +
**שרת MCP** (`https://ivr.pitronai.com/mcp`) שדרכו Claude קורא/כותב בקו
(סקיל `yemot-line-state`, זיכרון `reference-yemot-mcp`). מה שהוא מוסיף על
האתר של ימות (mitmachim topic/99818):
- טפסים ויזואליים בעברית לכל הגדרה מתקדמת (במקום עריכת ext.ini ידנית),
  בורר סוגי-שלוחה לפי קטגוריות, בונה ניתוב-מותנה ויזואלי.
- **יצירת מערכת מתיאור בשפה חופשית (AI)**, סריקת-תקינות (הגדרות שבורות,
  קבצים חסרים), ייצור אוטומטי של הודעת-תפריט מהשלוחות הקיימות.
- עורך אודיו בדפדפן (גל, חיתוך, אפקטים), פעולות-קבצים באצווה, גרירה לסידור.
- סטטיסטיקות האזנה עם תובנות AI, הרשאות משתמשים פר-שלוחה, ניהול כמה קווים.
- כניסה בסיסמת הקו, ואז מעבר לטוקן API ל"שימוש בייצור".

⚠ מגבלות שאומתו אצלנו: `plan_extension_changes` **משמיט מפתחות דינמיים**
(`050-option`) — להשלים דרך `UploadTextFile` של התוכנה; "פתרוןAI" הוא
יכולת של ה-MCP רק אם קיים לה כלי — אין להמציא מפתח ימות עבורה.

## 3. שכבה C — ספריות קוד פתוח לפי שפה

| ספרייה | שפה | מכסה | הערות |
|---|---|---|---|
| **yemot-router2** (ShlomoCode) | Node/TS, npm | **מודול API בשלוחה** | הפורק המתוחזק של yemot-router (383+ commits, MIT). תחביר Express-Router; שומר מצב שיחה בין בקשות ("קוד רציף" במקום goto); השמעה (טקסט/קובץ/TTS/ספרות/תאריך/זמנים), קלט (הקשות/זיהוי דיבור/הקלטה), ניתוב, שרת פרטי. **הבחירה ל-IVR דינמי ב-Node.** |
| yemot-router (MusiCode1) | Node | מודול API | המקור; פחות מתוחזק. |
| **yemot-api** (MusiCode1) | Node, npm | API חיצוני — מצומצם | רק `get_session`/`upload_file`/`download_file`. |
| **yemot-api** (zevisvei) | Python, pip `yemot-api` | **שניהם**: מודול API (בדיקת/הורדת/העברת קבצים, בניית תשובות read/go_to_folder) + REST | GPL-3. דוגמת FastAPI ב-README. **אצלנו לעיון בלבד** — `utils/yemot.py` נשאר המקור (הכרעה, סקיל `yemot-line-knowledge`). |
| **yemot** (pip `yemot`) | Python | API חיצוני | 4 מודולים: `Client`/`System`/`Campaign`/`IVR`. גרסה 0.1.2 (11/2025), לא פעיל, 0 כוכבים. |
| **HTP.Yemot.NET** (chaimhtp) | C#/.NET | מודול API | השמעה (TTS/קבצים/תאריך עברי/מוזיקה), קלט (הקשות/דיבור/הקלטה) עם `InputOptions` (מקלדת עברית/אנגלית/מייל), ניתוב. |
| הקוד שלנו — `utils/yemot.py` | Python, בלי תלויות | API חיצוני (קמפיינים, תבניות, קבצים, תזמון, ext.ini) + `CallbackTracker` | מכסה יותר מהספריות הציבוריות בתחום הקמפיינים; אין לו צד "מודול API" כי אין לנו שרת. |

**כלל בחירה:** צריך שהקו *יקרא לשרת שלך* בזמן שיחה → yemot-router2 (Node)
או yemot-api של zevisvei (Python). צריך *לנהל את הקו מבחוץ* → ה-API החיצוני
ישירות (urllib, כמו אצלנו) — הספריות הציבוריות דלות ולא מתוחזקות.

### אימות ל-API החיצוני: סיסמה מול API_KEY ואימות דו-שלבי (f2 topic/18564, post/159985; נבדק 09/09/2026)
ימות פרסמו תיעוד רשמי ל-2FA למפתחי ממשקים חיצוניים. שתי מסקנות שנוגעות ל-`utils/yemot.py`:
- **המלצת ימות: שרת/תוכנה יתחבר עם `API_KEY`, לא עם סיסמה.** הסיסמה נועדה
  להתחברות ראשונית של אדם בדפדפן בלבד. **`API_KEY` תקף ~חצי שנה** (מתחדש כל
  עוד בשימוש); טוקן-סשן רגיל תקף **30 דקות** בלבד. אצלנו כרגע `yemot_password`
  (עובד) — אם ההתחברות תיכשל פתאום עם שגיאת אימות, **החשד הראשון = מעבר ל-API_KEY**.
- **שירות `MFASession`** מנהל את ה-2FA (פעולות `sendMFA` שליחת קוד · `validMFA`
  אימות · `isPass` בדיקת-מעבר · `try`). אסימון "זכור אותי" עובד **ברמת כתובת IP**.
  ⚠ **השירות דורש רישיון פעיל בקו.** מקור-אמת מדויק לתחביר: post/159985 (חי).

### קטלוג המודולים הקהילתיים (topic/14490)
בפורום הרשמי יש **אינדקס של ~180 מודולי `type=api` ותוכנות-עזר** שהקהילה בנתה
(צינתוקים, אלפון, מייל/וואטסאפ, נוכחות, ניתוב, גוגל-שיטס ועוד). שמור אצלנו
ממופה לפי קטגוריה ב-`references/community-modules-index.md` — **לבדוק שם לפני
שכותבים מודול/כלי מאפס.** אותו קובץ כולל גם מקטע **מדריכי-הסבר מסודרים**
(topic/4996 + טיפים topic/4995) עם ההדרכות הכי רלוונטיות לנו (צינתוקים+TTS,
חסימות/רשימה-לבנה, אקסל/ymgr, קטלוג הודעות-המערכת Mxxxx).
⚠ ~90% מהמודולים כבר לא פעילים (הערך = השראה/דפוס),
ורובם דורשים שרת ביניים של היוצר; עצם מודול API אינו חושף את הקו, אבל הכנסת
סיסמת המערכת לכלי צד-שלישי כן (שכבה B).

## 6. מה **לא** קיים (נבדק 03/09/2026, לחסוך חיפוש חוזר)

- אין חנות-תוספים / "marketplace" רשמי; אין תוסף כרום/דסקטופ רשמי.
