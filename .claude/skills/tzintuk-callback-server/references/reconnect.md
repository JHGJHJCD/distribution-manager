## צעד 1 — מונע-הלולאה בשורש (מצב-ביניים בטוח, לא משנה התנהגות)
1. קרא **טרי**: `cur = yemot._download("ivr2:/ext.ini").decode("utf-8")`.
2. אם `check_did_and_go_to_folder_one_time=yes` כבר שם → דלג.
3. אחרת: `new = cur.rstrip("\n") + "\n" + "check_did_and_go_to_folder_one_time=yes" + "\n"`
   (מוסיף **רק** שורה אחת; שומר את שורת `campaign_message_to_play` הנוכחית מילה-במילה).
4. כתוב: `yemot._upload_multipart("ivr2:/ext.ini", new.encode("utf-8"), convert="0")`.
5. **אמת**: קרא חוזר, ודא שהשורה נכנסה, ששורת הקמפיין נשמרה, ושרק שורה אחת נוספה ואף
   שורה לא נמחקה (diff מול `cur`). אמת שהקו עדיין עונה (`get_system_overview`).

## צעד 2 — שורת הניתוב ב-Did_Go_To
1. קרא: `cur = yemot._download("ivr2:/Did_Go_To.ini").decode("utf-8")` (צפוי: `033060315=/555`).
2. `new = cur.rstrip("\n") + "\n" + "048691834=/76" + "\n"` (לא למחוק את השורה של רון!).
3. כתוב: `yemot._upload_multipart("ivr2:/Did_Go_To.ini", new.encode("utf-8"), convert="0")`.
   (ל-Did_Go_To.ini ה-MCP בד"כ מתיר write_text_file — אך ה-upload הגולמי עקבי ובטוח.)
4. **אמת**: קרא חוזר; שתי השורות קיימות. בדיקה חיה: חיוג ל-04 מ-0556752642 → לשמוע
   ישר את השאלה (אם המספר ברשימת השבוע) או תפריט רגיל בשקט (אם לא). חיוג ממספר אחר →
   תפריט רגיל מיד. לוודא שאין לולאה (השיחה לא נתקעת).

## צעד 3 — הדלקת המתג בתוכנה
- הגדרות → "שרת המענה" → "בדוק חיבור" (תקין), ואז הדלקה. או: `database.set_setting("cb_server_enabled","1")`
  (מסתנכרן למחשב השני). מכאן push בכל שליחה/תזמון, ו-answers מתמזג לתגי "אישר הגעה".
- בדיקה חיה מלאה: שליחת צינתוק (או "עדכן את שרת המענה" עם מספר בדיקה ברשימה) → חיוג
  חזרה ל-04 → הקשה 1 → לראות "אישר הגעה" בתוכנה.

## Rollback (ביטול מלא — בטוח)
- `Did_Go_To.ini` ← להחזיר ל-`033060315=/555` בלבד (כתיבה גולמית עם הגיבוי הטרי).
- שורש `ext.ini` ← למחוק **רק** את השורה `check_did_and_go_to_folder_one_time=yes`
  (קרא טרי, הסר את השורה, כתוב — שמור על שורת הקמפיין הנוכחית).
- `database.set_setting("cb_server_enabled","0")`.
- /76 אפשר להשאיר (לא מקושרת לכלום בלי השורה ב-Did_Go_To).
- אם "המספר לא זמין" לכל מחייגי 04 אחרי שינוי → זו **לא** תקלת ext.ini (רשת/מדיניות
  WHITELIST); החזר גיבוי, ובדוק את ברירת-המחדל של הקו (ראה `yemot-campaigns-ivr`).
