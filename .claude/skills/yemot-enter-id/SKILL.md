# כניסה מזוהה לשלוחה + קובץ נתונים + דוחות נוכחות

מנגנון מובנה של ימות המשיח: כל שלוחה יכולה לדרוש **מספר זיהוי** בכניסה, ואפשר
לצרף לכל מספר זיהוי **נתונים** (שם, שיוך/כיתה ועוד) שהמערכת מקריאה למתקשר
ומצמידה לדוחות. שימושי לחדרי ועידה / שידורים חיים עם מעקב נוכחות, ולכל שלוחה
שרוצים לפתוח רק למורשים.

מקורות (אומתו 01/09/2026): סרטון ההדרכה הרשמי https://youtu.be/3revikpdflg
(תמלול מלא: `references/tutorial-transcript.md`) + תיעוד הפורום הרשמי
https://f2.freeivr.co.il/topic/8204 (הגדרות הזיהוי בכלל המערכת).
ערכי ההגדרות כאן נלקחו מהתיעוד הכתוב — לא מקריאת-מסך של הסרטון.

## 1. בלוק ההגדרות ב-ext.ini של השלוחה

```ini
enter_id=yes                            ; חובה — מפעיל דרישת זיהוי בכניסה
enter_id_type=list_all_information      ; סוג הזיהוי (ראו טבלה)
record_name=no                          ; לא לבקש מהמתקשר להקליט את שמו
login_add_val_name=yes                  ; חובה לצירוף נתונים: מושך את השדות מהקובץ לשיחה ולדוח
say_name=val_name                       ; להקריא למתקשר את שמו מתוך הקובץ ("שלום ל-<שם>")
```

- המתקשר מקיש את המספר ומסיים ב-**סולמית** (#).
- `say_name` מקבל `yes` / `no` / `val_name`.
- **רציפות זיהוי:** אם כמה שלוחות באותה שיחה מוגדרות על **אותו** `enter_id_type`,
  המתקשר מקיש את הקוד פעם אחת בלבד — בשלוחות הבאות הוא עובר בלי הקשה חוזרת.
  לכן אפשר (ורצוי) לשים את הבלוק גם בשלוחת-האב וגם בכל חדרי הוועידה.

## 2. סוגי הזיהוי (enter_id_type) — הרשימה המלאה מהתיעוד

| ערך | מי נכנס |
|---|---|
| `teudat_zehut` | כל ת"ז ישראלית **תקינה** (בדיקת ספרת ביקורת בלבד, לא רשימה) |
| `digits` | כל מספר באורך הנדרש (ברירת מחדל 4 ספרות) |
| `list` | רק מספרים שמופיעים בקובץ `EnterIDList.ini` שבשלוחה |
| `phone` | כל מספר טלפון ישראלי תקין (חו"ל/חסוי — לא) |
| `enter_phone_list` | רק מספרי טלפון מתוך קובץ רשימה |
| `list_all_information` | רק מספרים מקובץ הנתונים המרכזי `EnterID/ListAllInformation.ini` (+ צירוף נתונים) |
| `phone_from_list_all_information` | זיהוי לפי מספר הטלפון של המתקשר מול קובץ הנתונים |
| `phone_or_enter_phone` | לפי הטלפון המזוהה, ואם חסוי — הקשה ידנית |
| `other_did` | לפי מספר ה-DID שחויג |

אורך במצב `digits`: `enter_id_type_digits_amount` (קבוע), או
`enter_id_type_digits_amount_minimum` + `enter_id_type_digits_amount_maximum` (טווח).
קובץ עזר `EnterIDValName.ini` — מיפוי מספר→שם להקראה בלבד (בלי שאר הנתונים).

## 3. קובץ הנתונים המרכזי — `EnterID/ListAllInformation.ini`

קובץ אחד לכל המערכת, בתיקייה בשם **המדויק** `EnterID` (רישיות חשובה!) בשורש.
כל שורה = רשומה, שדות מופרדים בפסיקים, לפי סדר העמודות הרשמי:

| עמודה | תוכן |
|---|---|
| A | מספר הזיהוי (קוד אישי / ת"ז / טלפון) |
| B | אישור: `1` = מורשה להיכנס, `0` = חסום |
| C | שם (זה מה שמוקרא ב-`say_name=val_name`) |
| D | משפחה |
| E | אימייל |
| F | מוסד / שיוך (בסרטון: הכיתה; מופיע בדוח) |
| G | סיסמה · H סכום · I חופשי · J עיר |

שורה לדוגמה (עמודות D,E ריקות = פסיקים ריקים):
```
222222222,1,יוסי כהן,,,כיתה א
55,1,בדיקה 2,,,כיתה ג
```
- קידוד **UTF-8** חובה (עברית).
- מספר הזיהוי יכול להיות בכל אורך (גם 2 ספרות וגם ת"ז מלאה, מעורבב באותו קובץ).

### יצירת התיקייה והקובץ

**דרך ה-API (הדרך שלנו, בלי אקסל):** בונים את שורות הטקסט בקוד ומעלים —
```python
from utils import yemot
rows = "222222222,1,יוסי כהן,,,כיתה א\n55,1,בדיקה 2,,,כיתה ג\n"
yemot._call("UploadTextFile", {"what": "ivr2:EnterID/ListAllInformation.ini",
                               "contents": rows}, post=True)
# אימות: yemot._call("GetTextFile", {"what": "ivr2:EnterID/ListAllInformation.ini"})
```
⚠ לא אומת בשטח אם UploadTextFile יוצר לבד את תיקיית `EnterID` כשאינה קיימת;
אם נכשל — ליצור אותה פעם אחת בממשק (המתכון של הסרטון) ולעדכן כאן.

**דרך ממשק הניהול (המתכון מהסרטון):**
1. ניהול קבצים → "צור שלוחה חדשה" (שם זמני כלשהו, למשל `000`).
2. בהגדרות המתקדמות שלה מקלידים תו כלשהו (נקודה) ושומרים → F5 —
   שלוחה **בלי `type=` פעיל** הופכת לתיקייה רגילה.
3. קליק ימני → שנה שם → `EnterID` (להעתיק, לא להקליד — רישיות!) → F5.
   התיקייה תופיע בתחתית עץ השלוחות.
4. את הקובץ בונים באקסל (עמודות A–F כנ"ל) → שמור-בשם CSV (Comma delimited) →
   פותחים ב-Notepad → שמור-בשם: שם `ListAllInformation.ini`, סוג All Files,
   קידוד UTF-8 → מעלים לתיקייה בגרירה ב"ניהול קבצים".

### מלכודות
- **קוד שמתחיל ב-0** — אקסל מוחק את האפס המוביל; לעצב את העמודה כ"טקסט" לפני
  ההקלדה (מהפורום, topic 18728). ביצירה דרך קוד — לא רלוונטי.
- לבדוק שהקובץ נקלט: עומדים על תיקיית `EnterID` → הגדרות מתקדמות → בוחרים את
  הקובץ ברשימה — רואים את התוכן כפי שהועלה.
- השבתת שורת הגדרה בלי למחוק: `;` בתחילת השורה.

## 4. דוחות נוכחות של חדרי ועידה — `LogConfBridgeEnterExit`

כשנכנסים לחדר ועידה עם זיהוי, המערכת מפיקה דוח HTML עם: שלוחה, טלפון, סוג
זיהוי, מספר זיהוי, שם, שיוך, תאריך (עברי+לועזי), שעת כניסה/יציאה, סה"כ זמן,
וסוג משתתף (מאזין / מנהל / broadcaster).

- **איפה:** (א) בתוך שלוחת חדר הוועידה עצמה — הקובץ עם אייקון זכוכית-המגדלת;
  (ב) בשלוחת הכניסה של הצוות — אותו דוח, המשתתף מסומן "מנהל";
  (ג) מרוכז לכל המערכת: תיקיית `Log` → `LogConfBridgeEnterExit`.
- **יומי מול חודשי לפי שם הקובץ:** `LogConfBridgeEnterExit-2020-04-21.html` = יומי;
  `LogConfBridgeEnterExit-2020-04.html` (בלי יום) = מרכז את כל החודש.
- מורידים את ה-HTML (חץ ההורדה) → קליק ימני → פתח באמצעות Excel → טבלה ניתנת
  לעריכה/סינון. (בקו שלנו יש גם `Log/LogFolderEnterExit-YYYY-MM.ymgr` לכניסות
  לשלוחות רגילות — ראו yemot-line-knowledge.)
