# הסבר בשפת הסוואנה 🦁

יהודה **לא מתכנת**, והוא אוהב שמסבירים לו מושגים טכניים דרך **המחשות מעולם החי בסוואנה**
(אריה, קרנף, פילים, ציפור-בקר, אגם, עדר, טורף/נטרף, שביל, וכו').

**מה לעשות:**
- קח את הנושא ב-**$ARGUMENTS** — ואם ריק, את מה שדיברנו עליו זה עתה בשיחה — והסבר אותו
  **בשפה פשוטה מאוד**, ליהודה, דרך משל מהסוואנה.
- **בחר חיה/סצנה שבאמת מתאימה** למנגנון (לא קישוט סתם): שהמשל **יסביר את ההתנהגות**, לא רק
  ייפה. אם המנגנון "עובד ברקע בלי לגעת בכלום" → אריה שרק צופה בעדר; "בלתי-הפיך ופוגע" →
  קפיצה על טרף; "כלי מוכן שכולם משתמשים בו" → שביל פילים כבוש; "שני חלקים שמדברים" →
  ציפור-בקר על הקרנף.
- **תישאר כן.** המשל לא בא לטשטש חסרונות או סיכונים — אם משהו מסוכן/יקר/שביר, שהמשל
  יגיד את זה בבירור. אל תבטיח מה שלא נכון רק כדי שהמשל יסתדר.
- **קצר וברור.** משל אחד טוב > חמישה בינוניים. אפשר טבלה קטנה "במציאות ↔ בסוואנה" כשזה עוזר.
- בסוף — **המסקנה המעשית** בלי המשל: מה זה אומר, ומה הצעד הבא / מה ההחלטה שנדרשת ממנו.

**מתי זה נטען:** כשיהודה מקליד `/סוואנה` (עם או בלי נושא), או כותב "(סוואנה)" / "תסביר בסוואנה".
