# תרגם הנחיה למודל 🔀

טען והפעל את הסקיל **prompt-translate**.

- ההנחיה לתרגום = **$ARGUMENTS**; אם ריק — קח את מה שיהודה כתב זה עתה בשיחה.
- אם לא נאמר לאיזה מודל (Claude / Gemini) — שאל שאלה ממוקדת אחת.
- אם חסר פרט קריטי בהנחיה — שאל שאלה אחת, אל תמציא.
- החזר את הפרומפט המתורגם בבלוק-קוד להעתקה + שורה אחת מה שינית ולמה.

הפירוט המלא (שני המצבים, שלדי הפרומפט לכל מודל) — בסקיל `prompt-translate`
ובקבצים `references/claude-style.md` / `references/gemini-style.md`.
