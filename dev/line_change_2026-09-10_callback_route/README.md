1. התוכנה סגורה בשני המחשבים.
2. גיבוי: להוריד את שני הקבצים (MCP `read_text_file` / פתרונאי) ולשמור כאן
   (`Did_Go_To.before.ini`, `ext.before.ini`).
3. לכתוב את שתי השורות (פתרונאי → קבצים, או `write_text_file`) — **ורק אותן**.
4. לוודא ש-/76 תקין: בתוכנה, הגדרות → "בדוק חיבור לשרת המענה" / או "תקן" מחלון
   הבדיקה לפני שליחה (כותב `api_wait_answer_music_on_hold=no` + `api_end_goto=/`).
5. אימות בטלפון (0556752642 עם סוד `TEST_PHONE` פעיל בשרת): לחייג ל-04 ← לשמוע
   ישר "יש לך חלוקה השבוע… 1/2/3" ← להקיש 1 ← "תודה" ← התפריט הרגיל.
   ואז מטלפון אחר: לחייג ל-04 ← תפריט רגיל מיד, בלי שום הודעה.
6. אחרי האימות: למחוק את הסוד `TEST_PHONE` (פיתוחים אישיים → סודות → עדכן פריסה).
