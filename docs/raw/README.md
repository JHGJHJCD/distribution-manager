# docs/raw — מקורות גולמיים (קפואים)

כאן נשמרים מקורות **כפי שהתקבלו**: תמלולי שיחות (למשל עם רון), הודעות/דוחות מהשטח, דפי תיעוד
שהועתקו, קובצי תכנון היסטוריים. שם קובץ: `YYYY-MM-DD-נושא.ext`.

כללים (דפוס LLM Wiki, ראה `CLAUDE.md` › "ניהול ידע"):
- **לא עורכים** קובץ כאן לעולם. תיקון = קובץ חדש עם תאריך חדש.
- כל קובץ שנכנס **מעובד** באותה הזדמנות: התובנות שלו נכנסות ל-`CLAUDE.md` / סקיל ב-`.claude/skills/` /
  זיכרון, עם הפניה חזרה לשם הקובץ כאן.
- ⚠ **בלי סודות** (סיסמאות/טוקנים/מספרי טלפון של מקבלים) — התיקייה נכנסת ל-git.
